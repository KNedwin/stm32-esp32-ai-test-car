电机

触发词（输入中文自动转GBK）

次数=1：刷到该卡立即播报并触发停车（整个上电周期仅触发一次）。
次数=N(≥2)：需 N 次有效刷卡，相邻两次有效刷卡间隔必须 ≥ 上方计数间隔，间隔不足不累计。
已触发的词之后只播报不再停车。示例：地球设2次/间隔10秒 → 刷一次，隔10秒以上再刷一次即停车。

读卡与播报
保存经 CLI 写入板内 Flash 并即时注入生效，无需重启；重启用于模拟断电验证参数保持
② 工具：编译与烧录

ISP 流程：先在上方连接串口 → 点本按钮（自动发 ISP 命令软跳 Bootloader 再调 stm32flash）。跳转前拔掉 U13T 读卡模块（其 RX 占用 USART1 干扰 ISP 应答），烧完插回。
