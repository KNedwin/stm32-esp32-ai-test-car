# 代码语义化

> 核心函数卡片（优先级 1 文件全部导出函数）

## components/common 纯逻辑（与 STM32 版逐字相同，语义见 stm32 知识库 10_代码语义化）
- rfid_logic.c: RfidLogic_Init/TriggerMatch/IsDup/UpdateSpeak/Process/RuleCount
- motor_logic.c: MotorLogic_Init/Step/IsInStopSequence/CalcStopTime/StateName
- card_parse.c: UartReceiveCommand/Card_Parse_Feed（帧解析 + 状态标志更新）

### 注入接口（2026-08 新增卡片）
| 函数 | 语义 |
|---|---|
| RfidLogic_SetConfig | 拷贝运行时规则到静态表 s_rules[8] 并置 cfg_ready；同步覆盖去重窗口 dedup_ms 与计数间隔 interval_ms |
| RfidLogic_RuleCount | 惰性 ensure_defaults 后返回当前规则数（未注入时从 TRIGGER_RULES 宏展开） |
| MotorLogic_SetTiming | 保存时序指针（默认指向 s_default_tm；调用方须保证 static/持久存储） |
| MotorLogic_Step | trigger 并入 pending_trigger；按绝对计时 t=tick-start_tick 推移状态机并返回本拍速度；RUN/SLOW 遍历 slowwin[] 判定多段降速 |
| MotorLogic_CalcStopTime | 电位器阻值→停车时间线性映射（含 adc≥4095 溢出钳 0 保护）；ESP32 已无调用方，保留供 STM32 |

## card_uart.c（读卡驱动）
| 函数 | 语义 |
|---|---|
| Card_Uart_Init | UART1 安装（环形缓冲 256B）→ 9600 发 0x2C → 50ms → uart_set_baudrate(115200)；全部 ESP_ERROR_CHECK |
| Card_ReadCard / Card_ReadBlock | 局部缓冲组帧（0x7F 头 + 异或校验 + 转义）→ uart_write_bytes + wait_tx_done |
| Card_Uart_Poll | uart_read_bytes(0 超时) 非阻塞取字节 → Card_Parse_Feed(buf[i], now_ms) |

## tts.c
| 函数 | 语义 |
|---|---|
| TTS_Init | UART2 安装（9600 8N1） |
| TTS_SetupDefaults | 发送 <S>3/<V>6/**<I>7**（语速/音量/上电提示选 7 号 + 断电保存），指令间 80/80/200ms 间隔（2026-08 修正 <I>7） |
| TTS_Send | 0 结尾字符串逐段 uart_write_bytes + wait_tx_done；DEMO_MODE=1 时改打印 hex |

## motor_drv.c
| 函数 | 语义 |
|---|---|
| Motor_Drv_Init | LEDC 定时器 20kHz 10-bit + 双通道配置（初始 DUTY_MAX） |
| Motor_Control | speed=0 → 双路 DUTY_MAX 同电位停；正转(dir=0) CH0=0、CH1=duty；反转(dir=1) 交换（2026-08 补方向） |
| Motor_SetDirection | 记录 s_motor_dir=dir&1，Motor_Control 按其选择恒低通道（2026-08 新增行） |

## rfid_process.c（读卡状态机）
- RFID_Init + RFID_Process：五态流转；绿色确认窗到期置 motor_trigger_flag（2026-08）；WAIT 真实时间差超时（重发 2 次后放弃）；NONE 200ms 探测；LEDLIGHT 先等 g_params.rfid_poll_ms 再 10ms 轮询、脱离 g_params.led_on_ms 灭灯；Motor_IsBusyForLed 期不碰 LED；数据经 RfidLogic_Process 决策
- RFID_HandleCardData：事件执行（EV_TRIGGER_STOP→s_trig_pending 绿窗 / EV_SPEAK(_FORCED)→TTS_Send + UpdateSpeak）；DBG_ECHO_RFID 时附 GBK→UTF-8 转换显示
- RFID_Speak / BufClear：播报与缓冲清理（上限 RFID_BLOCK_SIZE）

## motor_process.c（电机应用）
- （2026-08 重写）Motor_Init：g_params.target_speed/autostop_ms 直传 MotorLogic_Init（无 ADC 采样）；Motor_Process：每拍喂 MotorLogic_Step（传入 trigger 后清零标志）→ Motor_ApplySpeed(上限 MOTOR_SPEED_MAX)；状态变化边沿输出调试行并映射 WS2812 颜色
- Motor_IsInStopSequence：转发 MotorLogic_IsInStopSequence；Motor_IsBusyForLed：停车序列 ‖ RAMPUP

## 参数层与配网组件（2026-08 新增卡片）
| 函数 | 语义 |
|---|---|
| params_init | g_params=默认表 → nvs_flash_init（失败擦除重试）→ 读 blob(evcar/params)，len==sizeof 才采纳并 sanitize |
| params_sanitize | 全字段范围钳制；slowwins 冒泡排序+去重叠、rules 同词去重；返回修正字段数 |
| params_save | 先 sanitize 再 nvs_set_blob+commit |
| gbk_to_utf8 / utf8_to_gbk | GB2312⇄UTF-8 查表双向转换（8178 项）；非法字节降级 '?'，缓冲不足返负 |
| config_mode_boot_check | 读 esp_reset_reason 过滤异常复位 → NVS cnt++ → ≥3 进配网（消费计数）；否则蓝闪诊断并创建 cfgclr 清零任务 |
| config_mode_run | RGB 常亮蓝 → wifi_ap_start+web_server_start → 每 5s 查空闲 ≥300s 则 esp_restart() |
| wifi_ap_start | netif/事件循环容错初始化 → AP 模式 EV-Car-Setup/WPA2/12345678/信道1/4 连接 |
| web_server_start | httpd :80 注册 GET /、GET/POST /api/params、POST /api/restart；touch() 记录活动时间 |
| web_server_idle_seconds | (now-last_activity)/1e6 取整秒，供配网空闲退出判断 |
| WS2812_Init / WS2812_SetColor | RMT TX 通道(GPIO48,10MHz)+simple encoder；颜色表 GRB 序发送并等完成 |
| LED_Sta / LED_SetColor | 三引脚灯电平翻转 + WS2812 联动色（亮=绿/CARD，灭=微白/IDLE）；电机状态色经 SetColor 直设 |
