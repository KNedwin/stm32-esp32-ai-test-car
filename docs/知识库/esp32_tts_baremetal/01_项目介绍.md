# 项目介绍

## 1. 项目概述
esp32_tts_baremetal 是 STM32 复刻工程的 ESP32-S3 移植版（裸机版），功能与 STM32 版完全一致：U13T 读卡 + CN-TTS 播报 + 电机控制 + LED + 调试输出。共享纯逻辑层（rfid_logic/motor_logic/card_parse）与 STM32 版逐字相同。
（2026-08 更新）新增能力：运行时参数层（nvs_params，NVS 持久化）、WiFi 配网模式（连按 3 次 RST 触发，SoftAP+网页调参）、板载 WS2812 RGB 状态灯、电机转向参数、自动停车时长网页化（电位器硬件退役）。

## 2. 功能清单
| # | 功能 | 规格 | 参数 |
|---|---|---|---|
| 1 | 晚启动 | 通电延时 A=2s 后电机才启动 | MOTOR_START_LATE_TIME_MS |
| 2 | 缓启动 | B=4s 线性加速 0→999 | MOTOR_START_SLOW_TIME_MS / MOTOR_SPEED_MAX |
| 3 | 实时读卡 + LED | 任意时刻轮询读卡；读到卡 LED 亮；卡在线圈上持续亮，脱离 C=3s 后熄灭 | LED_ON_TIME_S |
| 4 | TTS 播报去重 | 单块 16 字节 GBK 送 TTS；D=10s 内相同内容不重复播报（LED 不受影响） | SPEAK_DEDUP_TIME_S |
| 5 | 定时降速 | 第 E=42s 起速度降为 F=50%，G=5s 后恢复（绝对计时，开机窗口仅一次） | MOTOR_TIME_START_S / MOTOR_SPEED_PERCENT / MOTOR_TIME_DURATION_S |
| 6 | 触发停车 | 多触发词规则表；停车序列 = 减速 H=2s + 静止 I=10s + 重新缓启动；每个词上电周期只触发一次 | TRIGGER_RULES / TRIGGER_STOP_RAMP_TIME_S / TRIGGER_WAIT_TIME_S |
| 7 | 自动永久停止 | 运行到 autostop_ms 即 STOP（网页可设 10~1000 秒，默认 300s；原电位器方案退役，MotorLogic_CalcStopTime 仅存共享层供 STM32） | params_t.autostop_ms |
| 8 | 数据输出口 | 实时输出读卡数据/电机状态/LED 状态（[SYS]/[RFID]/[LED]/[MOTOR] 格式） | DBG_ECHO_* |
| 9 | 系统保护 | 程序卡死自动重启（STM32: HardFault 复位；ESP32: 由 IDF 异常处理） | — |

## 3. 触发词行为矩阵（功能 6 详解）
| 场景 | 太阳（一次性，count_req=1） | 地球（计数型，count_req=2） |
|---|---|---|
| 第 1 次读到 | 播报 + 停车，标记"已触发" | 播报 + 亮灯，计数=1（未达次数按普通卡流程） |
| 第 2 次读到 | 正常播报亮灯（已触发，不再停车） | 距上次计数 ≥10s → 播报 + 停车，标记"已触发" |
| 触发之后 | 整个上电周期内不再触发，只播报亮灯（断电重启恢复） | 同左 |
| 10s 内重复刷 | 无影响（已触发） | 不计入次数（普通播报流程） |
| 停车序列期间 | 不计数不触发（播报流程照常） | 不计数不触发 |
| 触发时播报 | 强制播报（不受 D 秒去重约束，随后更新去重记录） | 同左 |
| LED | 始终照常亮 | 始终照常亮 |

> 停车序列：触发 → 绿色确认窗（TRIGGER_ACK_GREEN_MS=500ms 先亮绿）→ STOPPING（H=2s 线性减速）→ WAIT（I=10s 静止）→ RAMPUP（重启缓启动）→ RUN；共 H+I=12s。（2026-08 更新：新增绿窗环节）

## 4. 硬件组成
| 部件 | 型号/规格 | 接口 |
|---|---|---|
| 主控 | ESP32-S3（sdkconfig 设定 160MHz，512KB SRAM）（2026-08 修正：非 240MHz） | — |
| 读卡模块 | U13T（13.56MHz） | UART1 GPIO10/11 |
| 语音模块 | CN-TTS | UART2 GPIO12/13 |
| 电机 | 直流电机 + H 桥 | LEDC GPIO4/5 |
| 电位器 | **已退役**（GPIO1 悬空不再影响运行；驱动代码保留无调用方） | ADC1_CH0 GPIO1 |
| LED | 3 路 | GPIO2/8/9 |
| RGB 状态灯 | 板载 WS2812B | RMT GPIO48 |
| 调试输出 | USB-Serial-JTAG | 原生 USB |
| WiFi 配网 | SoftAP EV-Car-Setup（WPA2/12345678） | 板载天线 192.168.4.1 |

## 5. 技术栈
- 芯片: ESP32-S3；框架: ESP-IDF v6.0.2（newlib，FreeRTOS tick 1000Hz）
- 调度: app_main 单任务超级循环（+配置模式辅助任务 cfgclr）
- 共享组件: components/common（config/pins/驱动/纯逻辑/参数层/配网四件套）
- 托管组件: espressif/cjson ^1.7.3（web_server JSON 解析）
- 测试: esp32/tests（rfid_logic 32 + card_parse 14 + motor_logic 30 + gbk_utf8 11 + 漂移检查 = 87 项）（2026-08 更新）

## 6. 构建 / 烧录 / 调试
```bash
# 激活环境（每次编译前）
source <HOME>/.espressif/tools/activate_idf_v6.0.2.sh
# 构建
cd esp32/esp32_tts_baremetal && idf.py build
# 烧录 + 监视（USB-Serial-JTAG）
idf.py -p /dev/ttyACM0 flash monitor
# 主机单元测试（编译前必跑）
cd ../tests && ./run_tests.sh
```
