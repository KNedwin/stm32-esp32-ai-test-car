# 功能模块

## 1. 读卡驱动（components/common/card_uart.c|h）
- **职责**: UART1 驱动（环形缓冲，无 ORE 问题）、命令组帧（局部缓冲）、波特率切换、轮询消费
- **对外 API**: Card_Uart_Init/ReadCard/ReadBlock/Poll
- 初始化 API 均 ESP_ERROR_CHECK（配置错误立即暴露）

## 2. 帧解析（components/common/card_parse.c|h，纯逻辑）
- **职责**: U13T 帧解析状态机（长度≤31 防护、仅 0x91 产生事件、LEDLIGHT 卡在场刷新）
- **对外 API**: UartReceiveCommand/Card_Parse_Feed；now_ms 注入，主机可测

## 3. 触发/去重逻辑层（components/common/rfid_logic.c|h，四版共享）
- 与 STM32 版逐字相同（见 stm32 知识库 04_功能模块 §2）
- 本版行为要点：RfidLogic_Process 返回事件位掩码（NONE/SPEAK/SPEAK_FORCED/TRIGGER_STOP）；一次性词(count_req=1)首读即触发；计数型词首次数无条件放行、后续相邻有效计数须 ≥interval_ms，达 count_req 触发并清零计数；已触发词或停车序列期间按普通卡走去重播报；触发播报强制且随后更新去重记录
- （2026-08 新增）RfidLogic_SetConfig(rules, count, dedup_ms, interval_ms)：app_main 把 g_params.rules 注入静态规则表 s_rules[8]；不调用则回落 TRIGGER_RULES 宏默认（ensure_defaults 惰性初始化）

## 4. 电机状态机逻辑层（components/common/motor_logic.c|h，四版共享）
- 与 STM32 版逐字相同（见 stm32 知识库 04_功能模块 §3）
- 本版行为要点：IDLE→(t≥late)→RAMPUP(线性 0→target)→RUN；RUN 内遍历 slowwin[] 任一 [start,start+dur) 命中即 SLOW(pct%)；pending_trigger 在 RUN/SLOW 消费进 STOPPING(ramp_start 起线性减速 stop_ramp_ms)→WAIT(wait_ms)→RAMPUP；t≥stop_time 或 t≥1000s 进 STOP（停车序列期间不检查）
- （2026-08 新增）MotorLogic_SetTiming(&tm)：注入 late/slow/stop_ramp/wait + slowwin[8] 多段减速窗口；stop_time 由应用层从 g_params.autostop_ms 直传（MotorLogic_CalcStopTime 电位器公式仅存共享层供 STM32，ESP32 无调用方）

## 5. 电机驱动（components/common/motor_drv.c|h）
- **职责**: LEDC 双通道互补；Motor_Control(0~999)
- 映射：speed=0 → 两路 DUTY_MAX（同电位停）；speed>0 → CH0=0、CH1=speed×1023/999（差分电压）
- （2026-08 新增）Motor_SetDirection(dir)：dir=1 时交换两通道角色（CH1 恒低 + CH0 脉宽），app_main 上电用 g_params.motor_dir 应用网页转向设置

## 6. TTS（components/common/tts.c|h）
- **职责**: TTS_Init（UART2 9600）、TTS_Send（uart_write_bytes + 等发送完成）、TTS_SetupDefaults（<S>3/<V>6/<I>7 指令集下沉此处）
- （2026-08 修正）上电提示音指令为 **<I>7**（用户试听选定 7 号音效，commit 1ba84fc）；<I> 指令同时启用断电保存。DEMO_MODE=1 时 TTS_Send 改为打印待发帧 hex

## 7. LED / ADC / DEBUG（components/common/）
- led.c: 三引脚灯控 + WS2812 联动（LED_Sta(1)=绿灯/CARD，LED_Sta(0)=微白/IDLE）+ 边沿调试输出
- ws2812.c: RMT TX 驱动板载 WS2812B（GPIO48，10MHz 时基，rmt_new_simple_encoder callback 编码，GRB 字节序）（2026-08 新增）
- adc.c: adc_oneshot 采样——**电位器退役后无任何调用方**，代码保留编译（2026-08 标注）
- debug.c: Dbg_Printf → printf（USB-Serial-JTAG console，UTF-8 输出），局部缓冲可重入

## 8. 读卡应用（main/rfid_process.c）
- 五态流转 + 播报 + LED 保持 + NONE 态 200ms 低频探测（防询问模式模块失联）
- WAIT 超时用真实时间差（RFID_READ_TIMEOUT_MS），不依赖节拍
- （2026-08 更新）触发命中先进绿色确认窗（s_trig_pending，TRIGGER_ACK_GREEN_MS=500ms 到期置 motor_trigger_flag）；LEDLIGHT 态时序改读参数层：先等 g_params.rfid_poll_ms（播报延时）再每 RFID_LED_POLL_MS=10ms 轮询，卡脱离 g_params.led_on_ms 灭灯；停车序列/RAMPUP 期间不覆盖 RGB 颜色

## 9. 电机应用（main/motor_process.c）
- （2026-08 重写）Motor_Init 直接以 g_params.target_speed/g_params.autostop_ms 初始化 MotorLogic_Init——原"电位器 20 次采样→CalcStopTime"流程已删除
- Motor_Process 每拍喂 MotorLogic_Step（传入 trigger 后清零标志）→ Motor_Control；状态变化边沿映射 RGB 颜色（IDLE 蓝/RAMPUP 天蓝/RUN 微白/SLOW·STOPPING 黄/WAIT 红/STOP 灭）
- Motor_IsInStopSequence / Motor_IsBusyForLed：供 rfid 判断计数豁免与 LED 占用

## 10. 入口（main/app_main.c）
- 初始化顺序 + while(1) 超级循环
- （2026-08 更新）新增：params_init 加载 NVS 参数 → Motor_SetDirection(motor_dir) → config_mode_boot_check 配网检测 → static motor_timing_t 组装 slowwins 后 SetTiming/SetConfig 注入

## 11. 参数层（components/common/nvs_params.c|h）（2026-08 新增）
- **职责**: params_t 全量运行时参数的默认表（PARAMS_DEFAULT=config.h 宏值）、params_sanitize 范围钳制/排序去重、NVS blob 存取
- 存储：命名空间 `evcar`，key `params`，blob 整体读写；params_init 内完成 nvs_flash_init，读取时 len==sizeof(params_t) 才采纳（结构变更→回落默认一次）
- sanitize 要点：slowwins 按 start 升序冒泡+去重叠（保留先者）、触发词同内容去重、autostop_ms 钳 10s~1000s

## 12. GBK⇄UTF-8 转换（components/common/gbk_utf8.c|h + gbk_utf8_table.h）（2026-08 新增）
- **职责**: ASCII 直通 + GB2312 符号/一二级汉字双向映射（8178 项 s_gbk2uni 表，Flash 常量）；表外字符降级 '?'，缓冲不足返回负数
- 用途：调试口把卡内 GBK 转 UTF-8 显示；web_server 把网页 UTF-8 触发词转 GBK 存储、GET 时反向还原

## 13. 配网模式检测与宿主（components/common/config_mode.c|h）（2026-08 新增）
- **职责**: 手势=快速连按 3 次 RST（每次上电 NVS 计数 +1，键 evcar/cfg_cnt）；PANIC/看门狗/欠压复位不累计且保留计数；持续运行 10s 由 cfgclr 任务清零；上电按次数蓝闪诊断（被过滤红长亮 1s）
- 达阈值 → config_mode_run：RGB 常亮蓝 → wifi_ap_start + web_server_start → 循环每 5s 查 web_server_idle_seconds()≥300 则 esp_restart()（永不返回）

## 14. SoftAP 热点（components/common/wifi_ap.c|h）（2026-08 新增）
- **职责**: esp_netif/事件循环初始化（重复进入容错）→ WIFI_MODE_AP → SSID=EV-Car-Setup、WPA_WPA2_PSK 密码 12345678、信道 1、max_connection=4、IP 192.168.4.1
- 注意 wifi_ap.h 头注释仍写"开放网络"，与代码不符（见 07 已知问题）

## 15. Web 服务（components/common/web_server.c|h + webpage.html）（2026-08 新增）
- **职责**: httpd 端口 80；GET / 回内嵌配置页（EMBED_FILES 编入固件）；GET /api/params 出当前参数 JSON（触发词 GBK→UTF-8）；POST /api/params 收 JSON（*_s 秒×1000 存 ms、rules.text UTF-8→GBK）→ params_save 后应答并在 500ms 后 esp_restart()；POST /api/restart 直接重启
- 防护：POST 体上限 4096B；touch() 记录活动时间供空闲退出；webpage.html 含自动停车总时长字段（10~1000 秒）
