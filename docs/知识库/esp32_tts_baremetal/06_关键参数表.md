# 关键参数表

> （2026-08 更新）参数现分两层：config.h 宏为**编译期默认值**（首次烧录零感知）；运行时以 nvs_params 的 params_t 为准（网页改后存 NVS、重启生效，见 §6）。修改 config.h 后重新编译；触发词换词方法见 01_项目介绍 §3。

## 6. 运行时可调参数（nvs_params.h params_t，网页配置→NVS 持久化）（2026-08 新增）

> 网页单位统一秒，存储统一 ms；默认值=原 config.h 宏。sanitize 后存 NVS blob（命名空间 evcar/key params），重启由 params_init 加载全部生效。

| 字段 | 默认值(ms) | sanitize 范围 | 对应原宏 |
|---|---|---|---|
| late_ms | 2000 | 500~20000 | MOTOR_START_LATE_TIME_MS |
| slow_ms | 4000 | 500~30000 | MOTOR_START_SLOW_TIME_MS |
| target_speed | 999 | 100~999 | MOTOR_TARGET_SPEED |
| motor_dir | 0 | 0/1 | （新增能力） |
| slowwins[i].start_ms/dur_ms/pct | 42000/5000/50 | 0~3600000 / 200~120000 / 5~95，按 start 升序去重叠 | MOTOR_TIME_START_S/DURATION_S/SPEED_PERCENT |
| slowwin_count | 1 | ≤8（PARAM_SLOWWIN_MAX） | — |
| rules[i] word/len/count_req/speak_en | 太阳×1、地球×2 | len 1~16、count_req 1~10、同 GBK 词去重 | TRIGGER_RULES |
| rule_count | 2 | ≤8（PARAM_RULE_MAX） | — |
| count_interval_ms | 10000 | 1000~60000 | TRIGGER_COUNT_INTERVAL_MS |
| stop_ramp_ms | 2000 | 500~15000 | TRIGGER_STOP_RAMP_TIME_S |
| wait_ms | 10000 | 1000~120000 | TRIGGER_WAIT_TIME_S |
| led_on_ms | 3000 | 500~30000 | LED_ON_TIME_S |
| dedup_ms | 10000 | 500~60000 | SPEAK_DEDUP_TIME_S |
| rfid_poll_ms | 800 | 100~5000 | RFID_READ_DELAY_MS |
| autostop_ms | 300000 | 10000~1000000 | （替代电位器功能） |
