# 通信协议

## 1. U13T 读卡协议
### 帧格式（U13T 读卡模块）
`0x7F(帧头) + 长度 + 地址 + 命令码 + 参数 + 校验`；校验 = 长度^地址^命令码^参数 的异或；参数中的 0x7F 双写转义。

### 使用命令表
| 命令 | 方向 | 命令码 | 参数 |
|---|---|---|---|
| 读卡号 | → | 0x10 | 无 |
| 读卡号 | ← | 0x90 | 状态(1)+卡类型(2)+卡号(4) |
| 读块数据 | → | 0x11 | 块号(1) |
| 读块数据 | ← | 0x91 | 状态(1)+卡类型(2)+卡号(4)+数据(16) |
| 设波特率 | → | 0x2C | 波特率(4)+0x98 0x24 0x31（确认码） |
| 设波特率 | ← | 0xAC | 状态(1) |

### 状态码
| 状态码 | 意义 |
|---|---|
| 0x00 | 正确 |
| 0xFF | 无卡 |
| 0xFE | 错误或无卡 |
| 0xFB | 校验错误 |

### 读卡流程
- 单块 16 字节：先读块 4，块 4 首字节为 0 则回退读块 1；不做多块拼接
- 读块响应 20ms 无应答 → 重发；重发 2 次仍无应答 → 放弃回到无卡态
- 波特率：模块默认 9600，上电发 0x2C 命令切 115200（模块可能记忆，本机无条件跟随）


## 2. TTS 语音协议
（CN-TTS 模块）
- UART 9600 8N1，GBK 编码中文直接发送即播报
- 指令：`<S>3` 语速、`<V>6` 音量、`<I>7` 上电提示音选 7 号 + 断电保存（TTS_SetupDefaults 统一发送）（2026-08 修正：<I>0 为默认开、<I>n 实为选 n 号提示音，试听后选定 7 号；<I> 指令启用断电保存）


## 3. 数据输出口协议

| 事件 | 格式 |
|---|---|
| 上电 | `[SYS] boot   LED=OFF MOTOR=STOP` |
| 读到卡 | `[RFID] <HEX 字节空格分隔> = <UTF-8 中文>`（2026-08 增补：GBK→UTF-8 转换显示，需 DBG_ECHO_RFID=1） |
| LED 变化 | `[LED] ON` / `[LED] OFF`（边沿触发） |
| 电机状态变化 | `[MOTOR] <状态> speed=<速度>`（IDLE/RAMPUP/RUN/SLOW/STOPPING/WAIT/STOP） |
| 配网诊断 | `[CFG] rst_reason=<n> stored_cnt=<n>` / `[CFG] enter config mode: WiFi EV-Car-Setup -> http://192.168.4.1` / `[CFG] counter cleared ...` / `[CFG] idle timeout, restart`（2026-08 新增行） |

## 4. WiFi 配网 HTTP 协议（2026-08 新增）

### 链路参数
| 项目 | 值 | 来源 |
|---|---|---|
| 热点 SSID | EV-Car-Setup | wifi_ap.c |
| 认证/密码 | WPA_WPA2_PSK / 12345678 | wifi_ap.c |
| 信道 / 连接上限 | 1 / 4 | wifi_ap.c |
| 服务地址 | http://192.168.4.1（端口 80） | esp_netif 默认 |
| POST 体上限 | 4096 字节 | web_server.c post_params_handler |
| 空闲退出 | 无 HTTP 活动 ≥300s 自动重启 | config_mode.c |

### API 一览
| 方法/路径 | 功能 | 应答 |
|---|---|---|
| GET / | 配置页面（内嵌 webpage.html，UTF-8） | text/html |
| GET /api/params | 当前参数 JSON（ms 数值直出；rules[].text 为 GBK→UTF-8 中文） | application/json |
| POST /api/params | 提交参数：*_s 秒字段 ×1000 存 ms；slowwins[] 多段窗口；rules[].text UTF-8→GBK 存 NVS | `{"ok":true,"msg":"saved, restarting"}` 后 500ms 重启 |
| POST /api/restart | 不保存直接重启 | `{"ok":true,"msg":"restarting"}` 后 600ms 重启 |

### POST /api/params JSON 字段表
| 字段 | 单位 | 对应 params_t | sanitize 范围 |
|---|---|---|---|
| late_s / slow_s | 秒 | late_ms / slow_ms | 500~20000 / 500~30000 ms |
| target_speed | — | target_speed | 100~999 |
| motor_dir | — | motor_dir | 0 正转 / 1 反转 |
| stop_ramp_s / wait_s | 秒 | stop_ramp_ms / wait_ms | 500~15000 / 1000~120000 ms |
| led_on_s / dedup_s / poll_s | 秒 | led_on_ms / dedup_ms / rfid_poll_ms | 500~30000 / 500~60000 / 100~5000 ms |
| count_interval_s | 秒 | count_interval_ms | 1000~60000 ms |
| autostop_s | 秒 | autostop_ms | **10000~1000000 ms（网页限 10~1000s，默认 300s）** |
| slowwins[] {start_s,dur_s,pct} | 秒/% | slowwins[i] | start 0~3600000、dur 200~120000、pct 5~95，按 start 排序去重叠 |
| rules[] {text,count,speak} | — | rules[i] | len 1~16 字节、count_req 1~10、同词去重 |
