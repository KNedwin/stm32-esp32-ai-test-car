# 阅读指南

## 项目一句话
"esp32_tts_baremetal"：ESP32-S3 裸机版，实现 U13T 读卡 + CN-TTS 语音播报 + 电机控制（多触发词停车/定时降速/网页设定自动永久停止）+ LED/RGB 状态灯 + USB-Serial-JTAG 调试输出，支持 WiFi 配网页面在线调参。（2026-08 更新：电位器停止退役为网页自动停车）

## 关键提醒
- 共享组件在 ../components/common（两版唯一维护点，run_tests.sh 有漂移检查）
- 中文路径编译依赖 sdkconfig.defaults 的 CONFIG_LIBC_NEWLIB=y（勿删）
- 每次编译前先 `source ~/.espressif/tools/activate_idf_v6.0.2.sh`
- 可调参数分两层：config.h 编译期默认 → nvs_params 运行时参数（网页改后存 NVS 重启生效）；连按 3 次 RST 进配网模式（热点 EV-Car-Setup，密码 12345678，浏览器开 http://192.168.4.1）（2026-08 更新）
- FreeRTOS tick 已设 1000Hz（sdkconfig），vTaskDelay(1)=1ms；源码个别注释仍写 100Hz 属文档债（2026-08 更新）
