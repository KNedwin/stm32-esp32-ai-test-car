# 项目结构总览

## 1. 目录结构
```
esp32/
├── components/common/            # ★ 共享业务组件（两版唯一维护点）
│   ├── CMakeLists.txt            # idf_component_register(REQUIRES esp_driver_* esp_wifi esp_http_server cjson ...; EMBED_FILES webpage.html)
│   ├── idf_component.yml         # 托管依赖 espressif/cjson ^1.7.3（IDF v6 无内置 json）（2026-08 新增）
│   ├── config.h                  # 编译期默认参数（触发词表/时序/RGB 引脚/DEMO_MODE）
│   ├── pins.h                    # GPIO + UART/ADC/LEDC 实例映射
│   ├── nvs_params.c|h            # 运行时参数层（默认表/sanitize/NVS blob）（2026-08 新增）
│   ├── gbk_utf8.c|h(+table)      # GB2312⇄UTF-8 双向转换 8178 项表（2026-08 新增）
│   ├── rfid_logic.c|h            # 触发/去重纯逻辑（四版共享，Setter 注入）
│   ├── motor_logic.c|h           # 电机状态机纯逻辑（四版共享，Setter 注入 slowwin×8）
│   ├── card_parse.c|h            # 帧解析纯逻辑
│   ├── card_uart.c|h             # UART1 驱动（内嵌 DEMO_MODE 模拟器）
│   ├── tts.c|h                   # TTS 发送 + 默认设置(<I>7)
│   ├── motor_drv.c|h             # LEDC 电机驱动 + 转向
│   ├── led.c|h ws2812.c|h        # 三引脚灯 + 板载 RGB（RMT）（ws2812 2026-08 新增）
│   ├── config_mode.c|h           # 连按3次RST 配网检测+宿主循环（2026-08 新增）
│   ├── wifi_ap.c|h               # SoftAP EV-Car-Setup（2026-08 新增）
│   ├── web_server.c|h            # HTTP 页面+参数 JSON API（2026-08 新增）
│   ├── webpage.html              # 配置页面（EMBED 编入固件，含自动停车字段）（2026-08 新增）
│   ├── debug.c|h                 # console 输出封装
│   └── adc.c|h                   # 电位器 ADC（已退役，无调用方留编译）
└── esp32_tts_baremetal/                        # 本工程（仅应用层差异文件）
    ├── CMakeLists.txt            # EXTRA_COMPONENT_DIRS → ../components（必须在 project() 前）
    ├── sdkconfig.defaults        # USB-Serial-JTAG + CONFIG_LIBC_NEWLIB=y + CONFIG_FREERTOS_HZ=1000（2026-08 更新）
    ├── sdkconfig / dependencies.lock
    └── main/
        ├── CMakeLists.txt        # SRCS：app_main + rfid_process + motor_process，REQUIRES common
        ├── app_main.c            # 初始化序列(含参数加载/配网检测/逻辑注入) + 超级循环
        ├── rfid_process.c|h      # 读卡状态机（绿窗/参数化 LED 时序）
        └── motor_process.c|h     # 电机应用（autostop 参数化 + RGB 边沿映射）
```

## 3. 关键依赖与注意事项
- **共享组件**：components/common 是两版唯一维护点；run_tests.sh 漂移检查保证 main 仅 4 组差异文件
- **中文路径**：编译依赖 sdkconfig.defaults 的 CONFIG_LIBC_NEWLIB=y（勿删）；换 ASCII 路径可移除
- **构建**：EXTRA_COMPONENT_DIRS 必须在 project() 前设置；每次编译前 source 激活脚本
- **测试**：esp32/tests/run_tests.sh（rfid_logic 32 + card_parse 14 + motor_logic 30 + gbk_utf8 11 = 87 项 + 两版漂移检查）（2026-08 更新）
- **托管组件**：首次构建自动拉取 espressif/cjson（dependencies.lock 锁定）；webpage.html 经 EMBED_FILES 编入固件（2026-08 更新）
