# 硬件配置

## 1. 主控芯片
- **芯片**: ESP32-S3（Xtensa LX7 双核，512KB SRAM）✅代码确认
- **时钟**: CPU **160MHz**（sdkconfig:CONFIG_ESP_DEFAULT_CPU_FREQ_MHZ_160=y，2026-08 修正——非 240MHz）；XTAL 40MHz；FreeRTOS tick **1000Hz**（CONFIG_FREERTOS_HZ=1000）
- **时间基准**: esp_timer_get_time()（64 位 us，应用层截断为 ms 差值比较）

## 4. RGB 状态灯颜色表（WS2812B，GRB 字节序——写 RGB 会绿红颠倒）（2026-08 新增）
| 枚举 | RGB 值 | 含义 | 触发点 |
|---|---|---|---|
| LED_COLOR_BOOT | (0,0,60) 蓝 | 开机初始化/配网模式常亮 | WS2812_Init、motor IDLE 边沿、config_mode_run |
| LED_COLOR_IDLE | (10,10,10) 微白 | 空闲运行 / 三引脚灯灭时联动 | motor RUN 边沿、LED_Sta(0) |
| LED_COLOR_CARD | (0,60,0) 绿 | 读到卡 / 触发绿色确认窗(500ms) | LED_Sta(1)、s_trig_pending |
| LED_COLOR_SLOWING | (60,40,0) 黄 | 定时降速 SLOW / 触发减速 STOPPING | motor 状态边沿 |
| LED_COLOR_STOPPED | (60,0,0) 红 | 静止等待 WAIT（也用于复位被过滤提示） | motor WAIT 边沿、boot_check |
| LED_COLOR_RAMPUP | (0,50,60) 天蓝 | 缓启动 RAMPUP（含停车后重启） | motor RAMPUP 边沿 |
| LED_COLOR_OFF | (0,0,0) 灭 | 已永久停止 STOP / 诊断闪灯间隙 | motor STOP 边沿 |

> 设计约束（commit 98b332b/89d3324）：停车序列（STOPPING/WAIT）与 RAMPUP 期间 Motor_IsBusyForLed()=1，RFID 状态机不调用 LED_Sta 覆盖 RGB 颜色。
