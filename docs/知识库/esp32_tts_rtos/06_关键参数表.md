## 6. 运行时参数层（components/common/nvs_params.c|h，2026-08 新增章节）
网页单位统一秒，存储统一 ms；保存路径 = POST /api/params → utf8_to_gbk → params_save（sanitize+NVS blob "evcar"/"params"）→ 重启 params_init 加载。

| 参数 | NVS 字段 | 钳制范围 | 默认值 |
|---|---|---|---|
| 晚启动延时 | late_ms | 500~20000 ms | 2000 |
| 缓启动时长 | slow_ms | 500~30000 ms | 4000 |
| 目标速度 | target_speed | 100~999 | 999 |
| 电机转向 | motor_dir | 0/1 | 0=正转 |
| 减速窗口×N(≤8) | slowwins[].start_ms/dur_ms/pct | start≤3600000、dur 200~120000、pct 5~95；按 start 升序去重叠 | 42s 起 50% 持续 5s |
| 触发词×N(≤8) | rules[].word/len/count_req/speak_en | len 1~16、count_req 1~10；同词去重 | 太阳×1 / 地球×2 |
| 计数间隔 | count_interval_ms | 1000~60000 ms | 10000 |
| 停车减速 H | stop_ramp_ms | 500~15000 ms | 2000 |
| 静止等待 I | wait_ms | 1000~120000 ms | 10000 |
| 卡离场 LED 延时 C | led_on_ms | 500~30000 ms | 3000 |
| 播报去重窗口 D | dedup_ms | 500~60000 ms | 10000 |
| 读卡轮询间隔 | rfid_poll_ms | 100~5000 ms | 800 |
| **自动停车总时长** | autostop_ms | 10000~1000000 ms（网页 10~1000 秒） | 300000（5 分钟） |

- NVS blob 整块存储，读取时校验 `len == sizeof(params_t)`：结构变更（如新增 autostop_ms）导致旧数据尺寸不符 → 回落默认值一次，需重新配置。
- 未网页化仍由宏控制：RFID_READ_TIMEOUT_MS=20、RFID_LED_POLL_MS=10、NONE 态探测周期 200ms、TRIGGER_ACK_GREEN_MS=500。
