# 硬件配置

## 1. 主控芯片
- **芯片**: ESP32-S3（Xtensa LX7 双核，240MHz，512KB SRAM）✅代码确认
- **时钟**: 240MHz 主频（IDF 自动配置）；电机 PWM LEDC 20kHz 10-bit
- **时间基准**: esp_timer_get_time()（64 位 us，应用层截断为 ms）
