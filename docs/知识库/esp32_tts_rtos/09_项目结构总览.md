# 项目结构总览

## 1. 目录结构
```
esp32/
├── components/common/            # ★ 共享业务组件（两版唯一维护点）
│   ├── CMakeLists.txt            # idf_component_register(... EMBED_FILES webpage.html, REQUIRES esp_wifi/cjson ...)
│   ├── config.h                  # 编译期默认参数（触发词表/时序/DEMO_MODE/LED_WS2812_PIN）
│   ├── pins.h                    # GPIO + UART/ADC/LEDC 实例映射
│   ├── nvs_params.c|h            # 运行时参数层：params_t 默认表/sanitize/NVS blob（2026-08 新增）
│   ├── config_mode.c|h           # 连按3次RST 配网手势检测（2026-08 新增）
│   ├── wifi_ap.c|h               # SoftAP EV-Car-Setup（2026-08 新增）
│   ├── web_server.c|h            # HTTP 配置服务 + 参数 JSON API（2026-08 新增）
│   ├── gbk_utf8.c|h(+table.h)    # GB2312⇄UTF-8 转换 8178 项表（2026-08 新增）
│   ├── webpage.html              # 配置页面（EMBED 进固件，2026-08 新增）
│   ├── rfid_logic.c|h            # 触发/去重纯逻辑（四版共享）
│   ├── motor_logic.c|h           # 电机状态机纯逻辑（四版共享）
│   ├── card_parse.c|h            # 帧解析纯逻辑
│   ├── card_uart.c|h             # UART1 驱动（含 DEMO_MODE 模拟器）
│   ├── tts.c|h                   # TTS 发送 + 默认设置(<S>3/<V>6/<I>7)
│   ├── motor_drv.c|h             # LEDC 电机驱动 + 方向
│   ├── led.c|h / ws2812.c|h      # 三引脚 LED + WS2812B RGB(GPIO48)
│   ├── adc.c|h                   # 电位器采样（2026-08 起退役留编译）
│   └── debug.c|h                 # console 输出
└── esp32_tts_rtos/                        # 本工程（仅应用层差异文件）
    ├── CMakeLists.txt            # EXTRA_COMPONENT_DIRS → ../components（必须在 project() 前）
    ├── sdkconfig.defaults        # USB-Serial-JTAG console + FREERTOS_HZ=1000 + CONFIG_LIBC_NEWLIB=y（中文路径绕行）
    └── main/
        ├── CMakeLists.txt        # SRCS：app_main + rfid_task + motor_task，REQUIRES common
        ├── app_main.c            # 初始化 + 参数注入 + 配网检测 + 任务创建
        ├── rfid_task.c|h / motor_task.c|h
```

## 3. 关键依赖与注意事项
- **共享组件**：components/common 是两版唯一维护点；run_tests.sh 漂移检查保证 main 仅 4 组差异文件
- **中文路径**：编译依赖 sdkconfig.defaults 的 CONFIG_LIBC_NEWLIB=y（勿删）；换 ASCII 路径可移除
- **构建**：EXTRA_COMPONENT_DIRS 必须在 project() 前设置；每次编译前 source 激活脚本
- **测试**：esp32/tests/run_tests.sh（rfid_logic 32 + card_parse 14 + motor_logic 30 + gbk_utf8 11 = **87 项** + 两版漂移检查）（2026-08 更新：新增 gbk_utf8 组）
