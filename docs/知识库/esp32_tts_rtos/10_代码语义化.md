# 代码语义化

> 核心函数卡片（优先级 1 文件全部导出函数）

## components/common 纯逻辑（与 STM32 版逐字相同，语义见 stm32 知识库 10_代码语义化）
- rfid_logic.c: RfidLogic_Init/TriggerMatch/IsDup/UpdateSpeak/Process/RuleCount
- motor_logic.c: MotorLogic_Init/Step/IsInStopSequence/CalcStopTime/StateName
- card_parse.c: UartReceiveCommand/Card_Parse_Feed（帧解析 + 状态标志更新）

## card_uart.c（读卡驱动）
| 函数 | 语义 |
|---|---|
| Card_Uart_Init | UART1 安装（环形缓冲 256B）→ 9600 发 0x2C → 50ms → uart_set_baudrate(115200)；全部 ESP_ERROR_CHECK |
| Card_ReadCard / Card_ReadBlock | 局部缓冲组帧（0x7F 头 + 异或校验 + 转义）→ uart_write_bytes + wait_tx_done |
| Card_Uart_Poll | uart_read_bytes(0 超时) 非阻塞取字节 → Card_Parse_Feed(buf[i], now_ms) |

## tts.c
| 函数 | 语义 |
|---|---|
| TTS_Init | UART2 安装（9600 8N1，缓冲 256B） |
| TTS_SetupDefaults | 发送 <S>3/<V>6/**<I>7**（语速/音量/上电提示音选7号+断电保存），间隔 80/80/200ms（2026-08 更新：<I>0→<I>7） |
| TTS_Send | 0 结尾字符串逐段 uart_write_bytes + wait_tx_done；DEMO_MODE=1 改 printf hex 帧 |

## motor_drv.c
| 函数 | 语义 |
|---|---|
| Motor_Drv_Init | LEDC 定时器 20kHz 10-bit + 双通道配置（初始 DUTY_MAX） |
| Motor_SetDirection | 记录方向 s_motor_dir（0=正转 CH0 低+CH1 脉宽 / 1=反转交换）；app_main 上电按 g_params.motor_dir 应用 |
| Motor_Control | speed=0 → 双路 DUTY_MAX 同电位停；>0 → 按方向一路恒低、另一路 speed×1023/999 脉宽（差分电压）（2026-08 更新：接入方向分支） |

## nvs_params.c（2026-08 新增）
| 函数 | 语义 |
|---|---|
| params_init | g_params=默认表 → nvs_flash_init(失败擦除重试) → 读 NVS blob "evcar"/"params"（len==sizeof 才采纳并 sanitize） |
| params_sanitize | 全字段钳制：late/slow/pct/count_req 等；slowwins 排序去重叠；规则词去重；返回被修正字段数 |
| params_save | 先 sanitize 再 nvs_set_blob+commit 写回 |

## 配网组件（config_mode.c/wifi_ap.c/web_server.c/gbk_utf8.c，2026-08 新增）
| 函数 | 语义 |
|---|---|
| config_mode_boot_check | 读复位原因过滤崩溃类 → NVS cfg_cnt 累计 → 达 3 置配置模式并清计数 → 未达则蓝闪 cnt 次诊断 + 创建 10s 清零任务 |
| config_mode_run | RGB 常亮蓝 → wifi_ap_start + web_server_start → 每 5s 查空闲 ≥300s 则 esp_restart（不返回） |
| wifi_ap_start | netif/event 初始化（容错重复）→ SoftAP EV-Car-Setup/WPA2/12345678/ch1/max4 → esp_wifi_start |
| build_params_json (static) | g_params → cJSON（触发词 gbk_to_utf8 转 UTF-8 文本），调用方 free |
| apply_json_to_params (static) | JSON 字段(*_s 秒→ms)写入 g_params；触发词 utf8_to_gbk；数组截断到上限 |
| post_params_handler (static) | 收 ≤4096B body → cJSON 解析 → apply → params_save → 应答后 500ms esp_restart |
| gbk_to_utf8 / utf8_to_gbk | GB2312⇄UTF-8 双向查表转换（8178 项 s_gbk2uni；反查线性扫描置 0x8000 防歧义）；表外字符 '?'；缓冲不足返回负数 |

## ws2812.c（RGB LED）
| 函数 | 语义 |
|---|---|
| WS2812_Init | RMT TX 通道 GPIO48（10MHz，64 symbols，队列4）+ rmt_new_simple_encoder(callback) → 开机蓝色 |
| WS2812_SetColor | 查颜色表(RGB) → 重排 GRB 字节 → rmt_transmit + wait_all_done(200ms) |

## rfid_task.c（读卡任务）
- RFID_Task：先 vTaskDelay(500) 等语音模块上电 → TTS_SetupDefaults → 五态流转；WAIT 真实时间差超时（重发 2 次后放弃）；NONE 200ms 探测；LEDLIGHT g_params.rfid_poll_ms(默认800ms) 后每 10ms 轮询、脱离 g_params.led_on_ms(默认3s) 灭灯；数据经 RfidLogic_Process 决策；循环开头处理绿色确认窗到期置 motor_trigger_flag
- RFID_HandleCardData：事件执行（EV_TRIGGER_STOP→s_trig_pending 绿窗 / EV_SPEAK(_FORCED)→TTS_Send + UpdateSpeak）+ GBK→UTF-8 调试回显
- RFID_Speak / BufClear：播报与缓冲清理（上限 RFID_BLOCK_SIZE）

## motor_task.c（电机任务）
- Motor_Task：MotorLogic_Init(stop_time=g_params.autostop_ms) → 每拍 MotorLogic_Step（传入 trigger 后清零标志）→ Motor_Control；状态变化边沿输出 [MOTOR] 行并映射 RGB 状态色（IDLE蓝/RAMPUP天蓝/RUN微白/SLOW与STOPPING黄/WAIT红/STOP灭）
- Motor_IsInStopSequence：转发 MotorLogic_IsInStopSequence
- Motor_IsBusyForLed：停车序列或 RAMPUP 时返回 1，rfid 据此不覆盖 RGB 颜色
- （2026-08 更新：移除电位器 ADC 采样路径）
