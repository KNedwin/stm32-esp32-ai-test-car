# 功能模块

## 1. 读卡驱动（components/common/card_uart.c|h）
- **职责**: UART1 驱动（环形缓冲，无 ORE 问题）、命令组帧（局部缓冲）、波特率切换、轮询消费
- **对外 API**: Card_Uart_Init/ReadCard/ReadBlock/Poll
- 初始化 API 均 ESP_ERROR_CHECK（配置错误立即暴露）

## 2. 帧解析（components/common/card_parse.c|h，纯逻辑）
- **职责**: U13T 帧解析状态机（长度≤31 防护、仅 0x91 产生事件、LEDLIGHT 卡在场刷新）
- **对外 API**: UartReceiveCommand/Card_Parse_Feed；now_ms 注入，主机可测

## 3. 触发/去重逻辑层（components/common/rfid_logic.c|h，四版共享）
- 与 STM32 版逐字相同；RfidLogic_SetConfig 支持运行时规则注入（网页触发词），不调用则用 config.h TRIGGER_RULES 编译期默认
- 一次性词 count_req=1 首次即触发；计数型词首次数无条件放行、后续相邻有效计数间隔 ≥count_interval_ms；已触发词整个上电周期只播报；停车序列期间不计数不触发（in_stop_sequence 由调用方传入）（2026-08 更新：补充 Setter 注入与计数语义）

## 4. 电机状态机逻辑层（components/common/motor_logic.c|h，四版共享）
- 与 STM32 版逐字相同；MotorLogic_SetTiming 注入时序（late/slow/stop_ramp/wait + 多段减速窗口 slowwin[8]，按 start 升序遍历命中即 SLOW）（2026-08 更新：多段窗口支持）
- MotorLogic_CalcStopTime 电位器公式保留（共享层供 STM32 用；ESP32 已无调用方）

## 5. 电机驱动（components/common/motor_drv.c|h）
- **职责**: LEDC 双通道互补；Motor_Control(0~999) + Motor_SetDirection(0=正转/1=反转)
- 映射：speed=0 → 两路 DUTY_MAX（同电位停）；正转 speed>0 → CH0 恒低、CH1=speed×1023/999 脉宽；反转交换两路角色（差分电压）。Motor_SetDirection 接入 g_params.motor_dir（app_main 上电应用）（2026-08 更新：方向参数化）

## 6. TTS（components/common/tts.c|h）
- **职责**: TTS_Init（UART2 9600）、TTS_Send（uart_write_bytes + 等发送完成；DEMO_MODE=1 时改打印 hex 帧）、TTS_SetupDefaults（<S>3/<V>6/**<I>7** 指令集下沉此处；<I>7 为试听选定的上电提示音，<I> 同时启用断电保存）（2026-08 更新：<I>0→<I>7）

## 7. LED / RGB / DEBUG / ADC（components/common/）
- led.c: 三引脚灯控 + LED_Init（声明在 led.h）+ 边沿调试输出 + LED_SetColor 转发；LED_Sta(1) 同步 RGB 绿色（读到卡）、LED_Sta(0) 微白（空闲）
- ws2812.c: GPIO48 板载 WS2812B，RMT TX 驱动（rmt_new_simple_encoder + ws_encode_callback），字节序 GRB（RGB 表顺序会绿红颠倒），7 种状态色枚举 led_color_t
- adc.c: **已退役**——仍参与编译但无调用方（原电位器采样），宏与代码保留供回退（2026-08 更新）
- debug.c: Dbg_Printf → printf（USB-Serial-JTAG console），局部缓冲可重入

## 7.1 参数层（components/common/nvs_params.c|h）（2026-08 新增章节）
- params_t 全量运行时参数（默认值=config.h 宏）：params_init 上电加载 NVS blob（"evcar"/"params"，len==sizeof 不符回落默认一次）→ params_sanitize 钳制（autostop_ms 10~1000s、pct 5~95、窗口排序去重叠、规则词去重等）→ params_save 先 sanitize 再整块写回

## 7.2 配网组件（2026-08 新增章节）
- config_mode.c: 连按 3 次 RST 手势检测（NVS evcar/cfg_cnt 计数；PANIC/看门狗/欠压复位不累计；10s 后 cfg_clear_task 清零）；config_mode_run 启动 AP+HTTP 并做 5 分钟空闲自动重启退出
- wifi_ap.c: SoftAP EV-Car-Setup（WPA_WPA2_PSK，密码 12345678，信道 1，最大 4 连接，IP 192.168.4.1）
- web_server.c: GET / 内嵌 webpage.html；GET /api/params 出参 JSON（触发词 GBK→UTF-8 文本）；POST /api/params 收 JSON（≤4096B，触发词 UTF-8→GBK）→ params_save → 500ms 后 esp_restart；POST /api/restart 仅重启（600ms 延迟）
- gbk_utf8.c(+gbk_utf8_table.h): GB2312⇄UTF-8 双向转换，8178 项映射表 Flash 常量，ASCII 直通，表外字符降级 '?'，缓冲不足返回负数

## 8. 读卡应用（main/rfid_task.c）
- 五态流转 + 播报 + LED 保持 + NONE 态 200ms 低频探测（防询问模式模块失联）
- WAIT 超时用真实时间差（RFID_READ_TIMEOUT_MS），不依赖节拍
- 触发先入绿色确认窗（TRIGGER_ACK_GREEN_MS=500ms）到期才置 motor_trigger_flag，RGB 先亮绿再进停车序列
- LEDLIGHT 播报后延时与卡离场熄灯延时读 g_params.rfid_poll_ms / g_params.led_on_ms（默认 800ms/3s）（2026-08 更新：参数化接入）

## 9. 电机应用（main/motor_task.c）
- MotorLogic_Init(stop_time=g_params.autostop_ms) → 每拍喂 MotorLogic_Step → Motor_Control(speed)；状态变化边沿输出 [MOTOR] 行并映射 RGB 状态色（STOPPING/WAIT/RAMPUP 期间 Motor_IsBusyForLed()=1，rfid 不覆盖颜色）
- （2026-08 更新：移除电位器 ADC 采样与 ADC_Init 调用，stop_time 来自参数层）

## 10. 入口（main/app_main.c）
- 初始化顺序 + 参数注入（MotorLogic_SetTiming / RfidLogic_SetConfig）+ 配网检测 + xTaskCreatePinnedToCore 两任务（见 03_系统架构 §2）
