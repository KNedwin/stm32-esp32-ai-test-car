# 项目介绍

## 1. 项目概述
stm32_rfid_tts_baremetal 是"读卡语音播报程序源码 4.0 案例"的复刻工程（裸机版，芯片 STM32F103C8T6），用于新能源小车比赛场景：刷 NFC 卡（U13T 模块）→ TTS 播报卡内 GBK 中文 + 电机联动（触发词停车/定时降速/自动停车）。（2026-08 更新）新增串口配置模式：全部时序参数存内部 Flash（末页 0x0800FC00），经 USART3 行协议 CLI 在线查看/修改/保存，支持软跳 ISP 免拆烧录；配套 PC 图形上位机 tools/stm32_host。

## 2. 功能清单
| # | 功能 | 规格 | 参数 |
|---|---|---|---|
| 1 | 晚启动 | 通电延时 A=2s 后电机才启动 | MOTOR_START_LATE_TIME_MS |
| 2 | 缓启动 | B=4s 线性加速 0→999 | MOTOR_START_SLOW_TIME_MS / MOTOR_SPEED_MAX |
| 3 | 实时读卡 + LED | 任意时刻轮询读卡；读到卡 LED 亮；卡在线圈上持续亮，脱离 C=3s 后熄灭 | LED_ON_TIME_S |
| 4 | TTS 播报去重 | 单块 16 字节 GBK 送 TTS；D=10s 内相同内容不重复播报（LED 不受影响） | SPEAK_DEDUP_TIME_S |
| 5 | 定时降速 | 第 E=42s 起速度降为 F=50%，G=5s 后恢复（绝对计时，开机窗口仅一次） | MOTOR_TIME_START_S / MOTOR_SPEED_PERCENT / MOTOR_TIME_DURATION_S |
| 6 | 触发停车 | 多触发词规则表；停车序列 = 减速 H=2s + 静止 I=10s + 重新缓启动；每个词上电周期只触发一次 | TRIGGER_RULES / TRIGGER_STOP_RAMP_TIME_S / TRIGGER_WAIT_TIME_S |
| 7 | 自动停车 | 绝对计时到 autostop_ms 后永久停止（默认 300000ms=5 分钟，范围 10s~1000s）；（2026-08 更新）原"电位器自动停止"已退役——电位器硬件不再采样，MotorLogic_CalcStopTime 公式保留在共享层未用 | g_params.autostop_ms（默认宏见 nvs_params.c PARAMS_DEFAULT）/ MOTOR_MAX_RUN_TIME_MS(1000s 硬上限) |
| 8 | 数据输出口 | 实时输出读卡数据/电机状态/LED 状态（[SYS]/[RFID]/[LED]/[MOTOR] 格式） | DBG_ECHO_* |
| 9 | 系统保护 | 程序卡死自动重启（STM32: HardFault 复位；ESP32: 由 IDF 异常处理） | — |
| 10 | 串口配置模式（2026-08 新增） | USART3 行协议 CLI：HELP/GET all·win·rule/SET <key> <val>/SET win_add·win_del/rule_add·rule_del/SAVE/DUMP/ISP/REBOOT；每条修改即时生效(params_apply)，SAVE 写 Flash 断电保持；ISP 命令软跳系统 Bootloader 免 ST-Link 烧录 | config/param_cli.c、config/nvs_params.c、config/isp_jump.c |
| 11 | PC 上位机（2026-08 新增） | 浏览器图形页 ⇄ USART3 CLI 桥（http.server 默认 127.0.0.1:8321 + pyserial），参数载荷与 ESP32 网页同构（秒单位 JSON，中文 PC 侧转 GBK hex），附带编译/ST-Link 与 ISP 烧录按钮 | tools/stm32_host/{host.py,page.html,README.md} |

## 3. 触发词行为矩阵（功能 6 详解）
| 场景 | 太阳（一次性，count_req=1） | 地球（计数型，count_req=2） |
|---|---|---|
| 第 1 次读到 | 播报 + 停车，标记"已触发" | 播报 + 亮灯，计数=1（未达次数按普通卡流程） |
| 第 2 次读到 | 正常播报亮灯（已触发，不再停车） | 距上次计数 ≥10s → 播报 + 停车，标记"已触发" |
| 触发之后 | 整个上电周期内不再触发，只播报亮灯（断电重启恢复） | 同左 |
| 10s 内重复刷 | 无影响（已触发） | 不计入次数（普通播报流程） |
| 停车序列期间 | 不计数不触发（播报流程照常） | 不计数不触发 |
| 触发时播报 | 强制播报（不受 D 秒去重约束，随后更新去重记录） | 同左 |
| LED | 始终照常亮 | 始终照常亮 |

> 停车序列：触发 → STOPPING（H=2s 从当前速度线性减速到 0）→ WAIT（I=10s 静止）→ RAMPUP（重新缓启动 B=4s，不再经过晚启动）→ RUN。触发到重启共 H+I=12s。

## 4. 硬件组成
| 部件 | 型号/规格 | 接口 |
|---|---|---|
| 主控 | STM32F103C8T6（64KB/20KB） | — |
| 读卡模块 | U13T（13.56MHz，ISO14443A/B） | USART1 9600→115200 |
| 语音模块 | CN-TTS（GBK 合成） | USART2 9600 |
| 电机 | 直流电机 + H 桥 | TIM2 双路 PWM |
| 电位器 | 线性电位器——（2026-08 更新）**硬件退役**，ADC1_IN9 配置仍编译但无调用方 | ADC1_IN9（悬空不影响） |
| LED | 3 路（并联兼容） | PC13/PB12/PA8 |
| 数据输出 | USB 转 TTL | USART3 115200（调试 + 串口配置 CLI 收发） |

## 5. 技术栈
- 芯片: STM32F103C8T6（Cortex-M3 @72MHz）
- 框架: STM32CubeMX 6.17 + HAL 库
- 调度: 裸机主循环 + 非阻塞状态机
- 工具链: CMake + arm-none-eabi-gcc（Linux 直接编译）
- 共享纯逻辑: rfid_logic / motor_logic（四版逐字相同，主机单元测试覆盖）
- 上位机（2026-08 新增）: Python3 http.server + pyserial（tools/stm32_host，Windows/WSL 均可运行）
- 参数存储: 内部 Flash 末页 0x0800FC00（magic 0xA55A + CRC16-MODBUS，失败回落 config.h 默认）

## 6. 构建 / 烧录 / 调试
```bash
# 构建（产物 build/Debug/rfid_tts_baremetal.bin）（2026-08 更正 bin 名与 preset 路径）
cmake --preset Debug && cmake --build build/Debug    # 或 cmake -B build/Debug -G "Unix Makefiles"
# 烧录方式一：ST-Link
st-flash write build/Debug/rfid_tts_baremetal.bin 0x08000000
# 烧录方式二（2026-08 新增）：ISP 软跳——串口发 "ISP" 命令后 stm32flash 写入
#   ⚠️ 跳转前拔掉 U13T 读卡模块（其 RX 占用 USART1 干扰 Bootloader 应答）
stm32flash -w build/Debug/rfid_tts_baremetal.bin -v -g 0x0 /dev/ttyUSB0
# 调试口监视（USART3，也是串口配置 CLI 口）
screen /dev/ttyUSB0 115200
# 主机单元测试（编译前必跑）
cd ../../stm32/tests && ./run_tests.sh
# PC 上位机（可选）
python3 ../../tools/stm32_host/host.py    # http://127.0.0.1:8321
```
