# 阅读指南

## 项目一句话
"stm32_rfid_tts_baremetal"：STM32F103C8T6 裸机版，实现 U13T 读卡 + CN-TTS 语音播报 + 电机控制（多触发词停车/多段定时降速/自动停车）+ LED + USART3 调试与串口配置模式。（2026-08 更新：新增参数 Flash 存储、USART3 行协议 CLI、ISP 软跳烧录、PC 上位机 tools/stm32_host；电位器硬件退役改用固定自动停车时间）

## 代码导航速查
- 全部编译期默认参数: config.h
- 运行时参数(Flash 存储/钳制/注入): config/nvs_params.c
- 串口配置命令行(CLI): config/param_cli.c
- ISP 软跳 Bootloader / REBOOT: config/isp_jump.c
- 触发词行为: Task/rfid_logic.c
- 电机时序: Task/motor_logic.c
- 读卡状态机: Task/rfid_process.c
- 协议解析: hardware/rfid_card/Card.c
- PC 上位机: tools/stm32_host/{host.py,page.html}（仓库根）
- 构建: 见 01_项目介绍 §构建
