# 阅读指南

## 项目一句话
"stm32_rfid_tts_baremetal"：STM32F103C8T6 裸机版，实现 U13T 读卡 + CN-TTS 语音播报 + 电机控制（多触发词停车/定时降速/电位器停止）+ LED + 数据输出口。
