# 关键参数表

> 修改 config.h 后重新编译即为编译期默认；（2026-08 更新）大部分时序参数已支持运行时修改：存内部 Flash 的 g_params（见 §6），经 USART3 CLI 或 PC 上位机在线调整，SAVE 断电保持。触发词换词方法见 01_项目介绍 §3。

| 参数 | 值 | 可改性 | 含义 | 来源 |

| MOTOR_SPEED_MAX | 999 | ⚙️可改 | 电机速度上限 | config.h |

## 6. 运行时参数 g_params（2026-08 新增）

存储：内部 Flash 末页 0x0800FC00（1KB），flash_blob_t{magic=0xA55A, crc=CRC16-MODBUS, params_t}；上电 params_init 校验失败回落 config.h 默认。修改通道：USART3 CLI（SET <key> <val>，秒单位）或 PC 上位机 tools/stm32_host。

| CLI 键 | params_t 字段 | 默认值 | sanitize 范围 | 对应编译期宏 |
|---|---|---|---|---|
| late_s | late_ms | 2s | 0.5~20s | MOTOR_START_LATE_TIME_MS |
| slow_s | slow_ms | 4s | 0.5~30s | MOTOR_START_SLOW_TIME_MS |
| target | target_speed | 999 | ≤999 | MOTOR_TARGET_SPEED |
| dir | motor_dir | 0(正转) | 0/1 | —（新增能力） |
| sr_s | stop_ramp_ms | 2s | 0.5~15s | TRIGGER_STOP_RAMP_TIME_S |
| ws_s | wait_ms | 10s | 1~120s | TRIGGER_WAIT_TIME_S |
| led_s | led_on_ms | 3s | 0.5~30s | LED_ON_TIME_S |
| dedup_s | dedup_ms | 10s | 0.5~60s | SPEAK_DEDUP_TIME_S |
| poll_s | rfid_poll_ms | 800ms | 0.1~5s | RFID_READ_DELAY_MS |
| ci_s | count_interval_ms | 10s | 1~60s | TRIGGER_COUNT_INTERVAL_MS |
| as_s | autostop_ms | 300s | 10~1000s | —（新增能力） |
| win_add/win_del | slowwins[8] | 1 段：42s 起 5s 长 50% | start≤3600s、dur 0.2~120s、pct 5~95、排序去重叠 | MOTOR_TIME_START_S/DURATION_S/SPEED_PERCENT |
| rule_add/rule_del | rules[8] | 太阳(1次)/地球(2次) | len 1~16、count_req 1~10、词去重 | TRIGGER_RULES |

- 触发词 GBK 十六进制换算：`python -c "print(' '.join('\\x%02X' % b for b in '新词'.encode('gbk')))"`（CLI/上位机直接传中文由 PC 转 GBK）
- 即时生效机制：每条修改命令成功后 param_cli 调 params_apply() 注入 MotorLogic_SetTiming/RfidLogic_SetConfig；SAVE 后断电保持
