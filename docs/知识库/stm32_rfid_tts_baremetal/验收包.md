## Part 3：关键流程复核（5 个，客户对照确认）

### 流程 1：读卡数据流
步骤：UART 接收/轮询 → 帧解析 → card_res_flag → RFID 状态机 → chinese_data → RfidLogic_Process → 播报/触发
- ☐ 步骤描述准确  ☐ 有出入:______

### 流程 2：触发停车流程
步骤：命中规则 → EV_TRIGGER_STOP → motor_trigger_flag → MotorLogic_Step 消费 → STOPPING(2s)→WAIT(10s)→RAMPUP→RUN
- ☐ 步骤描述准确  ☐ 有出入:______

### 流程 3：电机缓启动流程
步骤：上电 IDLE → t≥A 进 RAMPUP → B 秒线性 0→999 → RUN；t∈[窗口 start,start+dur) 降速 pct%（默认 42s 起 50% 共 5s）
- ☐ 步骤描述准确  ☐ 有出入:______

### 流程 4：LED 保持流程
步骤：LEDLIGHT → 播报后 RFID_READ_DELAY_MS(800ms) → 每 g_params.rfid_poll_ms 轮询读卡号 → 回调刷新在场时间戳 → 脱离 g_params.led_on_ms 灭灯回 NONE（2026-08 更新：轮询/熄灯间隔接入运行时参数）
- ☐ 步骤描述准确  ☐ 有出入:______

### 流程 5：波特率切换流程
步骤：9600 初始化 → 先使能接收(防 ORE) → 发 0x2C → 等发送完成(TC 标志) → 本机重 init 为 115200（修正于 2026-08：源码无 50ms 延时，以 TC 标志为准）
- ☐ 步骤描述准确  ☐ 有出入:______

### 流程 6（新增）：串口配置参数修改流程（2026-08）
步骤：上位机/终端发 SET <key> <val> → ParamCli_Poll 组行解析 → g_params 更新 → params_apply() 即时注入逻辑层 → SAVE 写 Flash 0x0800FC00(magic+CRC16)
- ☐ 步骤描述准确  ☐ 有出入:______
