# 项目结构总览

## 1. 目录结构
```
stm32/rfid_tts_baremetal/
├── config.h                    # 编译期默认参数（触发词表/时序/开关）
├── config/                     # （2026-08 新增）参数与配置模式层
│   ├── nvs_params.c|h          # g_params Flash 持久化(0x0800FC00)+钳制+注入逻辑层
│   ├── param_cli.c|h           # USART3 行协议 CLI（GET/SET/SAVE/DUMP/ISP/REBOOT）
│   └── isp_jump.c|h            # ISP 软跳系统 Bootloader + REBOOT 钩子
├── Core/
│   ├── Inc/                    # CubeMX 生成头文件
│   └── Src/                    # main.c/usart.c/tim.c/adc.c/gpio.c/stm32f1xx_it.c（裸机无 freertos.c）
├── Drivers/                    # HAL 库 + CMSIS（CubeMX 生成，勿覆盖）

├── hardware/                   # 业务驱动
│   ├── USART/                  # BSP_USART（__io_putchar→USART2）
│   ├── rfid_card/              # Card.c|h（U13T 协议）
│   ├── pwm/                    # PWM.c|h（电机+Motor_SetDirection 正反转）
│   ├── LED/                    # led.c|h
│   ├── ADC/                    # BSP_ADC.c|h（电位器已退役，留编译）
│   └── DEBUG/                  # Debug.c|h（USART3 输出+CLI 应答）
├── Task/                       # 业务逻辑
│   ├── rfid_process.c|h / motor_process.c|h
│   ├── rfid_logic.c|h          # 触发/去重纯逻辑（四版共享，Setter 注入）
│   └── motor_logic.c|h         # 电机状态机纯逻辑（四版共享，Setter 注入）
├── CMakeLists.txt              # 根构建（业务源码含 config/*.c 在此，CubeMX 重生成不覆盖）
├── cmake/stm32cubemx/          # CubeMX 生成构建物（重生成会覆盖，勿手改）
└── build/                      # 编译产物（gitignore）

tools/stm32_host/               # （2026-08 新增，仓库根）PC 上位机 host.py/page.html/README.md
```

## 3. 关键依赖与注意事项
- **CubeMX 重新生成会覆盖 4 处**：USART2=9600、TIM2 CH2=PWM2、ADC 28.5 cycles、FreeRTOSConfig.h heap=8192（RTOS 版）
- **业务代码**：config.h/hardware/Task 独立目录 + USER CODE 区，重生成不受影响
- **printf 归 TTS（USART2）**，调试输出与 CLI 应答用 Dbg_Printf（USART3），勿混用
- **接线顺序（2026-08 更新）**：main.c USER CODE 2 区 params_init → params_apply → ParamCli_Init 必须先于 Motor_Init/RFID_Init（逻辑层注入先于使用）
- **测试**：stm32/tests/run_tests.sh（Card 25 + rfid_logic 32 + motor_logic 30 + 仿真 22）
