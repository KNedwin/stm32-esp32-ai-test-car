# 通信协议

## 1. U13T 读卡协议
### 帧格式（U13T 读卡模块）
`0x7F(帧头) + 长度 + 地址 + 命令码 + 参数 + 校验`；校验 = 长度^地址^命令码^参数 的异或；参数中的 0x7F 双写转义。

### 使用命令表
| 命令 | 方向 | 命令码 | 参数 |
|---|---|---|---|
| 读卡号 | → | 0x10 | 无 |
| 读卡号 | ← | 0x90 | 状态(1)+卡类型(2)+卡号(4) |
| 读块数据 | → | 0x11 | 块号(1) |
| 读块数据 | ← | 0x91 | 状态(1)+卡类型(2)+卡号(4)+数据(16) |
| 设波特率 | → | 0x2C | 波特率(4)+0x98 0x24 0x31（确认码） |
| 设波特率 | ← | 0xAC | 状态(1) |

### 状态码
| 状态码 | 意义 |
|---|---|
| 0x00 | 正确 |
| 0xFF | 无卡 |
| 0xFE | 错误或无卡 |
| 0xFB | 校验错误 |

### 读卡流程
- 单块 16 字节：先读块 4，块 4 首字节为 0 则回退读块 1；不做多块拼接
- 读块响应 20ms 无应答 → 重发；重发 2 次仍无应答 → 放弃回到无卡态
- 波特率：模块默认 9600，上电发 0x2C 命令切 115200（模块可能记忆，本机无条件跟随）


## 2. TTS 语音协议
（CN-TTS 模块）
- UART 9600 8N1，GBK 编码中文直接发送即播报
- 指令：`<S>3` 语速、`<V>6` 音量、**`<I>7` 上电提示音 7 号 + 断电保存**（2026-08 更新：原 <I>0 改为 <I>7，与 ESP32 版用户选定一致；裸机版在 RFID_Init 中发送）

## 3. 串口配置 CLI 协议（USART3 115200，2026-08 新增）
- 行协议：命令行以 \r\n 结尾；应答每行以 "> " 前缀输出到 USART3 调试口（Dbg_Printf，单条限 128 字节，HELP 拆两行）
- **命令字表**：
| 命令 | 数值/格式 | 方向 | 功能 | 来源 |
|---|---|---|---|---|
| HELP | 文本 | → | 两行列出全部命令 | config/param_cli.c:param_cli_execute |
| GET all | JSON | ← | `>{"late_s":..,"slow_s":..,"target":..,"dir":..,"sr_s":..,"ws_s":..,"led_s":..,"dedup_s":..,"poll_s":..,"ci_s":..,"as_s":..,"win_n":..,"rule_n":..}`（秒单位） | param_cli.c:82 |
| GET win | 多行+END | ← | 每窗口一行 `> W <i> <start_s> <dur_s> <pct>`，END 结尾 | param_cli.c:96 |
| GET rule | 多行+END | ← | 每规则一行 `> R <i> <gbkhex> <cnt> <spk>`，END 结尾 | param_cli.c:105 |
| GET <key> / SET <key> <val> | 标量 | →← | 键：late_s/slow_s/target/dir/sr_s/ws_s/led_s/dedup_s/poll_s/ci_s/as_s；成功 "> OK"，未知键 "> ERR:key" | param_cli.c:set_scalar |
| SET win_add <s> <d> <p> | 三参数 | →← | 追加降速窗口（满 8 条 "> ERR:full"） | param_cli.c:125 |
| SET win_del <i> | 索引 | →← | 删除第 i 个窗口（越界 "> ERR:range"） | param_cli.c:138 |
| SET rule_add <gbkhex> <cnt> <spk> | 三参数 | →← | 追加触发词（GBK 十六进制字节串） | param_cli.c:152 |
| SET rule_del <i> | 索引 | →← | 删除第 i 条触发词 | param_cli.c:168 |
| SAVE | — | →← | 写 Flash 末页，"> OK:saved"/"> ERR:save" | param_cli.c:184 |
| DUMP | — | →← | 打印 0x0800FC00 前 64 字节 hex（`> DUMP: xx xx..`） | param_cli.c:190 |
| ISP | — | →← | 应答 "> OK:entering ISP" 后软跳系统 Bootloader | param_cli.c:197 |
| REBOOT | — | →← | 应答 "> OK:reboot" 后 NVIC_SystemReset | param_cli.c:203 |
| （其他） | — | →← | "> ERR:unknown" | param_cli.c:208 |
- **即时生效**：每条修改命令成功后自动 params_apply() 注入逻辑层，无需重启；SAVE 后断电保持

## 4. 数据输出口协议

| 事件 | 格式 |
|---|---|
| 上电 | `[SYS] boot   LED=OFF MOTOR=STOP` |
| 读到卡 | `[RFID] <HEX 字节空格分隔>` |
| LED 变化 | `[LED] ON` / `[LED] OFF`（边沿触发） |
| 电机状态变化 | `[MOTOR] <状态> speed=<速度>`（IDLE/RAMPUP/RUN/SLOW/STOPPING/WAIT/STOP） |

> 注意（2026-08 强调）：USART3 同时承担本调试输出与 §3 的 CLI 应答；CLI 应答必须走 Dbg_Printf，printf 重定向在 TTS 语音口 huart2，混用会把应答文本播进喇叭。

## 5. PC 上位机 API（tools/stm32_host/host.py，2026-08 新增，非固件）
| 端点 | 方法 | 说明 |
|---|---|---|
| /api/ports | GET | 枚举本机串口 |
| /api/connect · /api/disconnect | POST | 打开/关闭串口（固定 115200） |
| /api/params | GET | 读板内参数（GET all/win/rule 三命令拼装，ms 字段，触发词转 UTF-8 文本） |
| /api/params | POST | 下发参数（秒单位 JSON 与 ESP32 网页同构；中文 PC 侧转 GBK hex；倒序删旧→逐条 SET→SAVE） |
| /api/reboot | POST | 发 REBOOT 复位 |
| /api/cli | POST | 原始 CLI 命令透传（如 DUMP） |
| /api/job | GET/POST | 编译(cmake)/烧录(ST-Link st-flash 或 ISP stm32flash)后台作业状态与日志 |
