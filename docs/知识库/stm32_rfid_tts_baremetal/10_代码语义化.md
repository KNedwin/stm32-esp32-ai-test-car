# 代码语义化

> 核心函数卡片（优先级 1 文件全部导出函数）

## rfid_logic.c（触发/去重纯逻辑）
| 函数 | 语义 |
|---|---|
| RfidLogic_Init | 清零触发计数/去重状态（上电调用一次） |
| RfidLogic_TriggerMatch | 在 data[len] 中逐规则子串搜索触发词；命中返回规则号，未命中 -1；空词条/超长词条防御 |
| RfidLogic_IsDup | last_speak 与本次内容相同且距上次播报 <D 秒 → 返回 1 |
| RfidLogic_UpdateSpeak | 播报后拷贝内容并记录时刻（去重基准） |
| RfidLogic_Process | 核心决策：匹配→已触发/停车序列→普通去重播报；count_req=1 直接触发；count_req>1 首次数放行+10s 间隔计数，达次触发；返回事件位掩码 |
| RfidLogic_RuleCount | 返回当前生效规则数（未注入时 ensure_defaults 按 TRIGGER_RULES 表 sizeof 推导） |
| RfidLogic_SetConfig（2026-08 新增） | 注入运行时规则表 rfid_rule_rt_t[8] + 去重/计数窗口，覆盖编译期默认（网页/CLI 配置用） |

## motor_logic.c（电机状态机纯逻辑）
| 函数 | 语义 |
|---|---|
| MotorLogic_SetTiming（2026-08 新增） | 注入运行时时序 motor_timing_t（A/B/H/I + 最多 8 段降速窗口），NULL 回落宏默认 |
| MotorLogic_Init | 记录绝对计时起点/目标速度/stop_time，状态置 IDLE，tm 指向当前注入时序 |
| MotorLogic_Step | 每拍状态机推进：pending_trigger 并入；IDLE→RAMPUP(缓启动 B 秒)→RUN；RUN/SLOW 内先消费触发→STOPPING(H 秒线性减速)→WAIT(I 秒静止)→RAMPUP 重启；再遍历 slowwins 命中任一 [start,start+dur) 进 SLOW(pct%)；t≥stop_time/1000s→STOP；返回本拍目标速度 |
| MotorLogic_IsInStopSequence | state∈{STOPPING,WAIT} 返回 1（供 rfid 不计数） |
| MotorLogic_CalcStopTime | 电位器均值→停车时间线性插值（clamp：adc≥4095→最短，负值钳 0，上限 RES_MAX） |
| MotorLogic_StateName | 状态枚举→字符串（调试输出） |

## rfid_process.c（读卡状态机）
| 函数 | 语义 |
|---|---|
| RFID_Init + RFID_Process | 读卡五态流转：EXIST 发读块→WAIT 20ms 超时重发(2 次后放弃)→RESDATA 单块处理→LEDLIGHT 轮询保持→NONE 低频探测；数据经 RfidLogic_Process 决策后置触发标志/播报 |
| RFID_HandleCardData | 调用 RfidLogic_Process 并执行事件动作（置 motor_trigger_flag / TTS 播报） |
| RFID_Speak | 送 TTS 并更新去重记录 |
| BufClear | 清缓冲（上限 16 字节，防越界） |

## motor_process.c（电机状态机）
| 函数 | 语义 |
|---|---|
| Motor_Init + Motor_Process | （2026-08 更新）Motor_SetDirection(g_params.motor_dir)+MotorLogic_Init(stop_time=g_params.autostop_ms)；每拍 MotorLogic_Step→ApplySpeed→Motor_Control；状态变化边沿 Dbg_Printf（电位器采样已退役） |
| Motor_ApplySpeed | 速度上限 999 钳制后调 Motor_Control |
| Motor_IsInStopSequence | 转发 MotorLogic_IsInStopSequence |

## config/nvs_params.c（参数存储，2026-08 新增）
| 函数 | 语义 |
|---|---|
| params_init | g_params=默认宏值；Flash 末页 magic==0xA55A 且 CRC16-MODBUS 匹配才采用 Flash 值并 sanitize 钳制 |
| params_save | sanitize 后组 flash_blob_t → 解锁 → FLASH_TYPEERASE_PAGES 擦 0x0800FC00 一页 → 按字编程 → 上锁；0=成功 |
| params_apply | g_params 组装 motor_timing_t/rfid_rule_rt_t[8] 经 MotorLogic_SetTiming/RfidLogic_SetConfig 即时注入 |
| params_sanitize | 各字段范围钳制、窗口排序去重叠、触发词去重；返回修正项数 |
| crc16 | CRC16-MODBUS（初值 0xFFFF，多项式 0xA001） |

## config/param_cli.c（串口配置 CLI，2026-08 新增）
| 函数 | 语义 |
|---|---|
| ParamCli_Init | 置 USART3->CR1.RE 使能接收（CubeMX 只配了发送） |
| ParamCli_Poll | 首次补开 RE；此后轮询 RXNE 逐字节组行（\b 退格、\r 忽略、\n 触发执行），LINE_MAX=192 |
| param_cli_execute | 行解析分发 HELP/GET(all·win·rule·key)/SET(标量+win_·rule_)/SAVE/DUMP/ISP/REBOOT；修改成功即 params_apply 并应答 OK |
| set_scalar | SET 标量键名映射到 g_params 字段（秒×1000 存 ms） |
| hex_to_bytes | GBK 十六进制串转字节（rule_add 用） |
| respond / Dbg_Printf 应答 | 统一 "> " 前缀输出 USART3；单条限 128B（HELP 拆两行） |
| ParamCli_ShouldEnterIsp | ISP 命令置位标志，主循环查询后软跳 |

## config/isp_jump.c（ISP 软跳与复位，2026-08 新增）
| 函数 | 语义 |
|---|---|
| ISP_Enter | 读 0x1FFFF000 的 MSP/PC → 关中断关 SysTick → HAL_RCC_DeInit → VTOR 指向 Bootloader → 设 MSP 跳转 |
| param_cli_do_isp / do_reboot | CLI 动作钩子实现：ISP 转 ISP_Enter；REBOOT 为 HAL_Delay(100)+NVIC_SystemReset |

## hardware/pwm/PWM.c（电机驱动）
| 函数 | 语义 |
|---|---|
| Motor_SetDirection（2026-08 新增） | 记录转向 dir&1（0 正转 CH2 脉宽 / 1 反转 CH1 脉宽） |
| Motor_Control | speed=0 双路 CCR=999 同电位停转；speed>0 按方向一路拉低另一路 CCR=speed 差分调速 |
| PWM_Init | HAL_TIM_PWM_Start 启动 TIM2 CH1/CH2 |
| PWM_DutySet | 按通道写 CCR1~CCR4 |

## Card.c（读卡协议）
| 函数 | 语义 |
|---|---|
| SetBound115200 | 组 0x2C 命令帧（9600 发送）切换模块波特率 |
| ReadCard / ReadBlock | 组 0x10/0x11 命令帧并发送（含 0x7F 转义） |
| UartReceiveCommand | 逐字节帧解析状态机（帧头/长度≤31/命令码/参数）；返回 0/1/2/3 |
| HAL_UART_RxCpltCallback | 按解析结果置 card_res_flag；LEDLIGHT 态读到卡号刷新 rfid_last_card_tick |
| HAL_UART_ErrorCallback | ORE 清标志 + 重装接收中断（自愈） |
