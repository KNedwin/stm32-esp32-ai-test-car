# 功能模块

## 1. 读卡协议驱动（hardware/rfid_card/Card.c|h）
- **职责**: U13T 模块命令组帧/发送、响应帧逐字节解析、波特率切换、接收中断回调
- **对外 API**: SetBound115200()、ReadCard()、ReadBlock(block)、UartReceiveCommand(data)、HAL_UART_RxCpltCallback、HAL_UART_ErrorCallback
- **关键逻辑**:
  - 帧解析状态机：0x7F 帧头 → 长度(≤31 防护) → 命令码/参数 → 仅 0x91（读块）产生事件、0x90 分"读到卡号/无卡"、0xAC 忽略
  - 回调：temp_res==2 在 LEDLIGHT 态刷新 rfid_last_card_tick（LED 常亮依据）；temp_res==3 不再主动熄灯
  - ErrorCallback：ORE 溢出自愈（清标志 + 重装接收中断）

## 2. 触发/去重逻辑层（Task/rfid_logic.c|h，四版共享）
- **职责**: 触发词匹配（子串搜索）、一次性/计数型计数（首次数放行 + 10s 间隔）、去重判断、事件输出
- **对外 API**: RfidLogic_Init/Process/TriggerMatch/IsDup/UpdateSpeak/RuleCount/SetConfig（2026-08 新增：RfidLogic_SetConfig(rules,count,dedup_ms,interval_ms) 运行时注入规则表，不调用则用 TRIGGER_RULES 编译期默认）
- **事件**: RFID_EV_NONE/SPEAK/SPEAK_FORCED/TRIGGER_STOP（位掩码）

## 3. 电机状态机逻辑层（Task/motor_logic.c|h，四版共享）
- **职责**: 绝对计时状态机（IDLE/RAMPUP/RUN/SLOW/STOPPING/WAIT/STOP）、多段降速窗口遍历、stop_time 判停
- **对外 API**: MotorLogic_Init/Step/IsInStopSequence/CalcStopTime/StateName/SetTiming（2026-08 新增：MotorLogic_SetTiming(motor_timing_t) 运行时注入 A/B/H/I 与 slowwin[8]，不调用则用宏默认）
- **pending_trigger**: IDLE/RAMPUP 期触发挂起，RUN/SLOW 消费
- （2026-08 更新）MotorLogic_CalcStopTime 电位器换算公式保留于共享层供 ESP32/历史版本，本版已无调用方

## 4. 读卡应用状态机（Task/rfid_process.c）
- **职责**: 五态流转（EXIST→WAIT→RESDATA→LEDLIGHT→NONE）、播报、LED 保持（tick 法）、触发标志置位
- 单块读取（块4→回退块1）；播报缓冲统一 chinese_data[16] 并强制 0 结尾
- （2026-08 更新）RFID_Init 上电提示音改 printf("<I>7")（原 <I>0，与 ESP32 选定一致）；LEDLIGHT 态 LED 熄灭延时与读卡轮询间隔改用 g_params.led_on_ms / g_params.rfid_poll_ms

## 5. 电机应用层（Task/motor_process.c）
- **职责**: 电位器 20 次采样 → MotorLogic_CalcStopTime → 每拍喂 MotorLogic_Step → Motor_Control 输出；状态变化边沿调试输出
- （2026-08 更新）电位器采样退役：Motor_Init 现为 Motor_SetDirection(g_params.motor_dir) + MotorLogic_Init(stop_time=g_params.autostop_ms)，不再调用 ADC；每拍流程不变（Step→ApplySpeed→边沿 Dbg_Printf）

## 6. TTS 发送（hardware/USART/BSP_USART.c|h）
- **职责**: printf 重定向（__io_putchar 强定义 → USART2）、Usartx_SendString
- 注意：printf 归 TTS（语音），调试输出请用 Dbg_Printf（USART3）

## 7. 电机驱动（hardware/pwm/PWM.c|h）
- **职责**: TIM2 双通道 PWM2 启动；Motor_Control(speed 0~999)；Motor_SetDirection(dir) 正反转
- 映射：speed=0 → 双路 CCR=999（同电位停）；speed>0 且 dir=0（正转）→ CH1=0、CH2=speed；dir=1（反转）→ CH1=speed、CH2=0（2026-08 新增：g_params.motor_dir 经 Motor_SetDirection 注入，TIM2 CH1/CH2 差分角色交换实现正反转）
- （2026-08 更新注释核实）PWM_DutySet 注释"CCR 越大高电平越长"对应 PWM2 模式下占空比语义以 tim.c OCMODE_PWM2 为准

## 8. LED（hardware/LED/led.c|h）
- **职责**: 三引脚（PC13/PB12/PA8）低电平亮；边沿触发调试输出（防 10ms 轮询刷屏）

## 9. 电位器采样（hardware/ADC/BSP_ADC.c|h）——硬件退役
- **职责**: Get_ADC_Value() 单次转换；公式（含 clamp）在 motor 层
- （2026-08 更新）**已退役**：全工程 grep 无 Get_ADC_Value/BSP_ADC 调用方，文件保留编译不删；PB1 引脚仍被 CubeMX 配置为模拟输入但悬空不影响运行

## 10. 数据输出口（hardware/DEBUG/Debug.c|h）
- **职责**: Dbg_Init（[SYS] boot）、Dbg_Printf（vsnprintf → USART3）；局部缓冲可重入
- （2026-08 更新）Dbg_Printf 兼任串口配置 CLI 应答通道（param_cli respond()）；printf 重定向在 TTS 口 huart2，绝不能用于 CLI 应答
## 11. 参数存储层（config/nvs_params.c|h，2026-08 新增）
- **职责**: params_t 同构参数（与 ESP32 nvs_params 完全同构）的 Flash 持久化、校验恢复、范围钳制、注入逻辑层
- **对外 API**: params_init() / params_save() / params_apply() / params_sanitize(p)
- **关键逻辑**:
  - 存储：内部 Flash 末页 flash_blob_t{magic=0xA55A, crc16, params_t}，地址 0x0800FC00（64KB 版最后 1KB）
  - params_init：magic+CRC16-MODBUS(poly 0xA001) 双校验通过才采用，否则整体回落 PARAMS_DEFAULT（=config.h 宏）；读入后再 sanitize 钳制一次
  - params_save：HAL_FLASH_Unlock → FLASH_TYPEERASE_PAGES 整页擦除 → FLASH_TYPEPROGRAM_WORD 按 4 字节编程 → Lock；返回 0=成功
  - params_apply：把 g_params 组装为 motor_timing_t + rfid_rule_rt_t[8]，调 MotorLogic_SetTiming / RfidLogic_SetConfig 即时生效
  - params_sanitize：各字段钳制（late 0.5~20s、slow 0.5~30s、slowwin start≤3600s/dur 0.2~120s/pct 5~95 并排序去重叠、rule len 1~16/count 1~10/去重词、autostop 10s~1000s 等）

## 12. 串口配置 CLI（config/param_cli.c|h，2026-08 新增）
- **职责**: USART3 行协议解析，在线读写 g_params，触发 ISP/REBOOT 动作
- **对外 API**: ParamCli_Init()（置 USART3->CR1.RE 开接收）/ ParamCli_Poll()（RXNE 轮询组行）/ ParamCli_ShouldEnterIsp() / param_cli_execute(line)（纯逻辑可主机测试）
- **命令集**（应答行 "> " 前缀走 Dbg_Printf，单条限 128B）:
  - `HELP`（拆两行）、`GET all|win|rule|<key>`、`SET <key> <val>`（键：late_s/slow_s/target/dir/sr_s/ws_s/led_s/dedup_s/poll_s/ci_s/as_s，秒单位）
  - `SET win_add <s> <d> <p>` / `win_del <i>` / `SET rule_add <gbkhex> <cnt> <spk>` / `rule_del <i>`（上限各 8 条）
  - `SAVE`（写 Flash）、`DUMP`（打印 0x0800FC00 前 64 字节 hex）、`ISP`、`REBOOT`
- **关键逻辑**: 每条修改命令成功后自动 params_apply() 即时生效无需重启；\b 退格支持；LINE_MAX=192；动作经 weak 钩子 param_cli_do_isp/do_reboot 由 isp_jump.c 实现

## 13. ISP 软跳与复位（config/isp_jump.c|h，2026-08 新增）
- **职责**: 收到 ISP 命令后软跳芯片出厂系统 Bootloader（USART1 ISP），REBOOT 复位重启
- **对外 API**: ISP_Enter()；钩子实现 param_cli_do_isp()/param_cli_do_reboot()
- **关键逻辑**: 读 0x1FFFF000 处 MSP/PC → __disable_irq → 关 SysTick(CTRL/LOAD/VAL=0) → HAL_RCC_DeInit → SCB->VTOR=0x1FFFF000 → set_MSP → 跳转；do_reboot 为 HAL_Delay(100)+NVIC_SystemReset
- **注意**: 跳转前必须拔 U13T 读卡模块（其 RX 占用 USART1 会干扰 Bootloader 应答）；main 循环收到 ShouldEnterIsp 后 HAL_Delay(100) 留足应答时间再跳

## 14. PC 上位机（仓库根 tools/stm32_host/{host.py,page.html,README.md}，2026-08 新增，非固件源码）
- **职责**: 浏览器图形配置页 ⇄ USART3 CLI 的串口事务桥 + 编译/烧录工具
- **构成**: host.py = http.server（默认 127.0.0.1:8321）+ pyserial SerialBridge（静默 0.30s 判收包完成，保证 GET win/rule 多行应答完整）+ 后台作业线程（编译/烧录日志轮询）；page.html = 与 ESP32 网页同构表单
- **API**: GET /api/ports·params·job；POST /api/connect·disconnect·params·reboot·cli·job(build/flash_stlink/flash_isp)
- **要点**: 参数载荷秒单位 JSON 与 ESP32 网页同构，中文由 PC 侧转 GBK hex 下发；下发顺序为先查数量→倒序删旧→逐条加新→SAVE；编译经 wsl.exe 包装调 cmake（Windows），烧录支持 ST-Link(st-flash --connect-under-reset) 与 ISP(先发 ISP 命令再 stm32flash)
