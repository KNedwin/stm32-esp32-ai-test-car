# 通信协议

## 1. U13T 读卡协议
### 帧格式（U13T 读卡模块）
`0x7F(帧头) + 长度 + 地址 + 命令码 + 参数 + 校验`；校验 = 长度^地址^命令码^参数 的异或；参数中的 0x7F 双写转义。

### 使用命令表
| 命令 | 方向 | 命令码 | 参数 |
|---|---|---|---|
| 读卡号 | → | 0x10 | 无 |
| 读卡号 | ← | 0x90 | 状态(1)+卡类型(2)+卡号(4) |
| 读块数据 | → | 0x11 | 块号(1) |
| 读块数据 | ← | 0x91 | 状态(1)+卡类型(2)+卡号(4)+数据(16) |
| 设波特率 | → | 0x2C | 波特率(4)+0x98 0x24 0x31（确认码） |
| 设波特率 | ← | 0xAC | 状态(1) |

### 状态码
| 状态码 | 意义 |
|---|---|
| 0x00 | 正确 |
| 0xFF | 无卡 |
| 0xFE | 错误或无卡 |
| 0xFB | 校验错误 |

### 读卡流程
- 单块 16 字节：先读块 4，块 4 首字节为 0 则回退读块 1；不做多块拼接
- 读块响应 20ms 无应答 → 重发；重发 2 次仍无应答 → 放弃回到无卡态
- 波特率：模块默认 9600，上电发 0x2C 命令切 115200（模块可能记忆，本机无条件跟随）


## 2. TTS 语音协议
（CN-TTS 模块）
- UART 9600 8N1，GBK 编码中文直接发送即播报
- 指令：`<S>3` 语速、`<V>6` 音量、`<I>7` 上电提示音 7 号 + 断电保存（2026-08 更新：由 <I>0 改为 <I>7，与 ESP32 版试听选定一致；rfid_task.c:37-41 统一发送）


## 3. 数据输出口协议

| 事件 | 格式 |
|---|---|
| 上电 | `[SYS] boot   LED=OFF MOTOR=STOP` |
| 读到卡 | `[RFID] <HEX 字节空格分隔>` |
| LED 变化 | `[LED] ON` / `[LED] OFF`（边沿触发） |
| 电机状态变化 | `[MOTOR] <状态> speed=<速度>`（IDLE/RAMPUP/RUN/SLOW/STOPPING/WAIT/STOP） |

## 4. 参数配置命令行协议（USART3，2026-08 新增）

> 收发同口 115200 8N1；行以 \r\n 结尾（支持退格，行缓冲 192 字节）；接收为 defaultTask 10ms 轮询 RXNE。**应答必须走 Dbg_Printf（本口）——printf 重定向在 TTS 语音口 huart2，误用会把应答播报出来。**

### 命令表
| 命令 | 格式 | 功能 | 成功应答 |
|---|---|---|---|
| HELP | `HELP` | 输出两行命令说明（Dbg_Printf 单条限 128 字节故拆两行） | cmds: ... |
| GET all | `GET` 或 `GET all` | 单行 JSON 全部标量参数（秒单位）+ win_n/rule_n | > {...} |
| GET <key> | `GET late_s` 等 | 暂不支持单键（等价 all 分支外报 ERR:key） | — |
| GET win | `GET win` | 逐降速窗口一行 `> W i start_s dur_s pct`，END 结尾 | >W... + END |
| GET rule | `GET rule` | 逐触发词一行 `> R i gbkhex cnt spk`，END 结尾 | >R... + END |
| SET 标量 | `SET late_s\|slow_s\|target\|dir\|sr_s\|ws_s\|led_s\|dedup_s\|poll_s\|ci_s\|as_s <val>` | 改对应 g_params 字段（秒×1000→ms），即时 params_apply | OK |
| SET win_add | `SET win_add <start_s> <dur_s> <pct>` | 追加降速窗口（上限 8 组，ERR:full） | OK |
| SET win_del | `SET win_del <i>` | 删除第 i 个窗口 | OK / ERR:range |
| SET rule_add | `SET rule_add <gbkhex> <cnt> <spk>` | 追加触发词规则（hex 大小写不敏感，len=hex 长度/2，上限 8 条） | OK |
| SET rule_del | `SET rule_del <i>` | 删除第 i 条规则 | OK / ERR:range |
| SAVE | `SAVE` | sanitize 后擦写 Flash 末页（magic+CRC16），断电保持 | OK:saved / ERR:save |
| DUMP | `DUMP` | 输出 Flash 参数页前 64 字节 hex | > DUMP: ... |
| ISP | `ISP` | 应答后软跳系统 Bootloader（0x1FFFF000）串口烧录 | OK:entering ISP |
| REBOOT | `REBOOT` | HAL_Delay(100) 后 NVIC_SystemReset | OK:reboot |
| （未知） | — | — | ERR:unknown / ERR:args / ERR:key |

### 即时生效机制
每条修改命令（SET 系列、SAVE）成功后自动调用 params_apply()：把 g_params 经 MotorLogic_SetTiming/RfidLogic_SetConfig 注入逻辑层，无需重启。

### PC 上位机（tools/stm32_host/host.py）
- 浏览器表单 ⇄ host.py（HTTP 127.0.0.1:8321）⇄ pyserial 串口事务桥 ⇄ 本协议
- 参数载荷与 ESP32 网页同构（秒单位 JSON，rules.text 中文由 PC 侧转 GBK hex）
- 附带编译（wsl.exe 包装 cmake）与烧录按钮（ST-Link st-flash 或 ISP 软跳+stm32flash）
- 连接成功自动 GET all/win/rule 填充表单；API：/api/ports、/api/connect、/api/params、/api/reboot、/api/cli、/api/job
