# 关键参数表

> 修改 config.h 后重新编译；触发词换词方法见 01_项目介绍 §3。
> （2026-08 更新）下表宏值为**编译期默认**：上电被 params_init() 装入 g_params（Flash 末页有有效参数则以存储值为准），并经 params_apply() 注入逻辑层。运行时可用 USART3 命令行或 PC 上位机免编译修改（范围见 §6），SAVE 后断电保持。

## 4. 自动停车时间（2026-08 更新：电位器退役）

| 参数 | 值 | 可改性 | 含义 | 来源 |
|---|---|---|---|---|
| autostop_ms | 300000 | ⚙️可改(CLI 键 as_s) | 上电到自动永久停车的总时长（绝对计时）；Motor_Init 直接取 g_params.autostop_ms | config/nvs_params.c:28 |
| RES_MAX | 5000 | 🔒不建议改 | 电位器阻值量程（CalcStopTime 插值用，已无调用方） | config.h |
| STOP_TIME_MIN_MS | 10000 | 🔒不建议改 | 停车时间下限（同上保留） | config.h |
| STOP_TIME_MAX_MS | 600000 | 🔒不建议改 | 停车时间上限（同上保留） | config.h |

## 6. 运行时参数 g_params（2026-08 新增：CLI/上位机可调范围）

> 默认值=config.h 宏（见上各节）；params_sanitize() 钳制范围如下。修改即时生效（params_apply），SAVE 后存 Flash 断电保持。

| 参数(CLI 键) | 默认值 | 允许范围 | 含义 |
|---|---|---|---|
| late_ms(late_s) | 2000 | 500~20000 ms | A 晚启动延时 |
| slow_ms(slow_s) | 4000 | 500~30000 ms | B 缓启动时长 |
| target_speed(target) | 999 | ≤999 | 目标速度 |
| motor_dir(dir) | 0 | 0~1 | 转向：0=正转(CH2 脉宽)，1=反转 |
| slowwins[i](win_add/win_del) | {42s,5s,50%}×1 | start 0~3600s / dur 200~120000ms / pct 5~95% | 降速窗口表（自动按 start 排序、删除重叠项、上限 8 组） |
| rules[i](rule_add/rule_del) | 太阳(1次)/地球(2次) | len 1~16B / count_req 1~10 / speak_en 0~1 | 触发词规则（重复词条自动去重，上限 8 条） |
| count_interval_ms(ci_s) | 10000 | 1000~60000 ms | 计数型词两次有效计数间隔 |
| stop_ramp_ms(sr_s) | 2000 | 500~15000 ms | H 触发停车减速时长 |
| wait_ms(ws_s) | 10000 | 1000~120000 ms | I 停住静止等待时长 |
| led_on_ms(led_s) | 3000 | 500~30000 ms | C 卡脱离后 LED 熄灭延时 |
| dedup_ms(dedup_s) | 10000 | 500~60000 ms | D 播报去重窗口 |
| rfid_poll_ms(poll_s) | 800 | 100~5000 ms | LED 保持期轮询读卡号间隔（默认=RFID_READ_DELAY_MS） |
| autostop_ms(as_s) | 300000 | 10000~1000000 ms | 上电到自动永久停车总时长 |
