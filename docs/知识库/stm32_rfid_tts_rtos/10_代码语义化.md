# 代码语义化

> 核心函数卡片（优先级 1 文件全部导出函数）

## rfid_logic.c（触发/去重纯逻辑）
| 函数 | 语义 |
|---|---|
| RfidLogic_Init | 清零触发计数/去重状态（上电调用一次） |
| RfidLogic_TriggerMatch | 在 data[len] 中逐规则子串搜索触发词；命中返回规则号，未命中 -1；空词条/超长词条防御 |
| RfidLogic_IsDup | last_speak 与本次内容相同且距上次播报 <D 秒 → 返回 1 |
| RfidLogic_UpdateSpeak | 播报后拷贝内容并记录时刻（去重基准） |
| RfidLogic_Process | 核心决策：匹配→已触发/停车序列→普通去重播报；count_req=1 直接触发；count_req>1 首次数放行+10s 间隔计数，达次触发；返回事件位掩码 |
| RfidLogic_RuleCount | 返回当前生效规则数（未注入时由 TRIGGER_RULES 表 sizeof 推导） |
| RfidLogic_SetConfig | （2026-08 新增）注入运行时规则表+去重窗口+计数间隔，覆盖编译期默认；params_apply 调用 |

## motor_logic.c（电机状态机纯逻辑）
| 函数 | 语义 |
|---|---|
| MotorLogic_Init | 记录绝对计时起点/目标速度/stop_time，状态置 IDLE；tm 指向当前生效时序 |
| MotorLogic_SetTiming | （2026-08 新增）注入运行时电机时序（A/B/H/I/多段降速窗口），NULL 回落默认宏 |
| MotorLogic_Step | 每拍状态机推进：pending_trigger 并入；IDLE→RAMPUP(缓启动 B 秒)→RUN；RUN/SLOW 内消费触发→STOPPING(H 秒线性减速)→WAIT(I 秒静止)→RAMPUP 重启；t≥stop_time/1000s→STOP；返回本拍目标速度 |
| MotorLogic_IsInStopSequence | state∈{STOPPING,WAIT} 返回 1（供 rfid 不计数） |
| MotorLogic_CalcStopTime | 电位器均值→停车时间线性插值（clamp：adc≥4095→最短，负值钳 0，上限 RES_MAX） |
| MotorLogic_StateName | 状态枚举→字符串（调试输出） |

## rfid_task.c（读卡任务）
| 函数 | 语义 |
|---|---|
| RFID_Task | 读卡五态流转：EXIST 发读块→WAIT 20ms 超时重发(2 次后放弃)→RESDATA 单块处理→LEDLIGHT 按 g_params.rfid_poll_ms 轮询保持→NONE；上电 <S>3/<V>6/<I>7 设置；熄灭延时 g_params.led_on_ms |
| RFID_HandleCardData | 调用 RfidLogic_Process 并执行事件动作（置 motor_trigger_flag / TTS 播报） |
| RFID_Speak | 送 TTS 并更新去重记录 |
| BufClear | 清缓冲（上限 16 字节，防越界） |

## motor_control_task.c（电机任务）
| 函数 | 语义 |
|---|---|
| Motor_Init | （2026-08 更新）Motor_SetDirection(g_params.motor_dir) + MotorLogic_Init(HAL_GetTick(), g_params.target_speed, g_params.autostop_ms) + 输出 0；电位器采样已移除 |
| Motor_Control_Task | 每拍取走 motor_trigger_flag → MotorLogic_Step → Motor_ApplySpeed 输出；状态变化边沿 Dbg_Printf；osDelay(1) |
| Motor_ApplySpeed | 速度钳 999 后调 Motor_Control |
| Motor_IsInStopSequence | 转发 MotorLogic_IsInStopSequence |

## Card.c（读卡协议）
| 函数 | 语义 |
|---|---|
| SetBound115200 | 组 0x2C 命令帧（9600 发送）切换模块波特率 |
| ReadCard / ReadBlock | 组 0x10/0x11 命令帧并发送（含 0x7F 转义） |
| UartReceiveCommand | 逐字节帧解析状态机（帧头/长度≤31/命令码/参数）；返回 0/1/2/3 |
| HAL_UART_RxCpltCallback | 按解析结果置 card_res_flag；LEDLIGHT 态读到卡号刷新 rfid_last_card_tick |
| HAL_UART_ErrorCallback | ORE 清标志 + 重装接收中断（自愈） |

## nvs_params.c（参数存储与注入，2026-08 新增）
| 函数 | 语义 |
|---|---|
| params_init | g_params 先装默认宏值；读 Flash 末页 magic==0xA55A 且 CRC16MODBUS 通过则采用存储值并 sanitize |
| params_save | 副本 sanitize → 擦 0x0800FC00 页（FLASH_TYPEERASE_PAGES）→ 按 4 字节 HAL_FLASH_Program 写 blob → 返回 0=成功 |
| params_apply | g_params → motor_timing_t/rfid_rule_rt_t[] → MotorLogic_SetTiming + RfidLogic_SetConfig 注入逻辑层 |
| params_sanitize | 全字段范围钳制；降速窗口按 start 排序并删除重叠项；触发词去重/len/count_req/speak_en 合法化；返回修正数 |
| crc16 | CRC16-MODBUS（初值 0xFFFF，多项式 0xA001），对 params_t 字节校验 |

## param_cli.c（串口命令行，2026-08 新增）
| 函数 | 语义 |
|---|---|
| ParamCli_Init | 置 USART3 CR1_RE 使能接收（CubeMX 只配了发送） |
| ParamCli_Poll | 轮询 RXNE 收字节：\r 忽略、\n 触发行执行、退格回删、行缓冲上限 192 |
| param_cli_execute | 解析一行命令：HELP/GET(all/win/rule)/SET(标量+win_*/rule_*)/SAVE/DUMP/ISP/REBOOT；修改类成功后 params_apply 即时生效；应答一律 Dbg_Printf |
| set_scalar | 标量关键字→g_params 字段映射（秒×1000），未知键返回 0 |
| hex_to_bytes | GBK hex 字符串→字节数组（rule_add 用） |
| ParamCli_ShouldEnterIsp | 返回 ISP 请求标志（defaultTask 检查后延时跳转） |
| param_cli_do_isp/do_reboot | 弱符号动作钩子，由 isp_jump.c 实现 |

## isp_jump.c（ISP 软跳，2026-08 新增）
| 函数 | 语义 |
|---|---|
| ISP_Enter | 读 Bootloader 向量（MSP/PC）→关中断→停 SysTick→HAL_RCC_DeInit→VTOR=0x1FFFF000→set_MSP→跳转出厂 Bootloader |
| param_cli_do_isp | 钩子实现：调 ISP_Enter |
| param_cli_do_reboot | 钩子实现：HAL_Delay(100) 后 NVIC_SystemReset |
