# 项目结构总览

## 1. 目录结构
```
stm32/stm32_rfid_tts_rtos/
├── config.h                    # 全部可调参数（触发词表/时序/开关）
├── Core/
│   ├── Inc/                    # CubeMX 生成头文件
│   └── Src/                    # main.c/usart.c/tim.c/adc.c/gpio.c/freertos.c(RTOS版)/stm32f1xx_it.c
├── Drivers/                    # HAL 库 + CMSIS（CubeMX 生成，勿覆盖）
├── Middlewares/                   # FreeRTOS 源码（RTOS 版）
├── hardware/                   # 业务驱动
│   ├── USART/                  # BSP_USART（__io_putchar→USART2）
│   ├── rfid_card/              # Card.c|h（U13T 协议）
│   ├── pwm/                    # PWM.c|h（电机 + Motor_SetDirection 转向）
│   ├── LED/                    # led.c|h
│   ├── ADC/                    # BSP_ADC.c|h（已退役，留编译）
│   └── DEBUG/                  # Debug.c|h（USART3 输出 + CLI 应答）
├── config/                     # （2026-08 新增）参数化底座
│   ├── nvs_params.c|h          # g_params 运行时参数：Flash 末页存储+CRC+注入逻辑层
│   ├── param_cli.c|h           # USART3 行协议命令行（HELP/GET/SET/SAVE/DUMP/ISP/REBOOT）
│   └── isp_jump.c|h            # ISP 软跳系统 Bootloader 0x1FFFF000
├── Task/                       # 业务逻辑
│   ├── rfid_task.c|h / motor_control_task.c|h / freertos.c 任务创建
│   ├── rfid_logic.c|h          # 触发/去重纯逻辑（四版共享，SetConfig 注入）
│   └── motor_logic.c|h         # 电机状态机纯逻辑（四版共享，SetTiming 注入）
仓库根 tools/stm32_host/        # （2026-08 新增）PC 上位机 host.py+page.html+README
├── CMakeLists.txt              # 根构建（业务源码在此，CubeMX 重生成不覆盖）
├── cmake/stm32cubemx/          # CubeMX 生成构建物（重生成会覆盖，勿手改）
└── build/                      # 编译产物（gitignore）
```
## 2. 文件地图

|---|---|---|
| main.c | 初始化 + 调度 | main/SystemClock_Config |

| tim.c | TIM2 PWM | MX_TIM2_Init |
| adc.c | ADC1 | MX_ADC1_Init |
| Card.c | 读卡协议 | UartReceiveCommand |
| rfid_logic.c | 触发/去重 | RfidLogic_Process |
| motor_logic.c | 电机状态机 | MotorLogic_Step |
| rfid_task.c | 读卡状态机 | RFID_Task |
| motor_control_task.c | 电机应用 | Motor_Control_Task |
| BSP_USART.c | printf 重定向 | __io_putchar |

| param_cli.c | 串口命令行 | param_cli_execute/ParamCli_Poll |
| isp_jump.c | ISP 软跳 | ISP_Enter |

## 3. 关键依赖与注意事项
- **CubeMX 重新生成会覆盖 4 处**：USART2=9600、TIM2 CH2=PWM2、ADC 28.5 cycles、FreeRTOSConfig.h heap=8192（RTOS 版）
- **业务代码**：config.h/hardware/Task 独立目录 + USER CODE 区，重生成不受影响
- **printf 归 TTS（USART2）**，调试输出用 Dbg_Printf（USART3），勿混用
- **测试**：stm32/tests/run_tests.sh（Card 25 + rfid_logic 32 + motor_logic 30 + 仿真 22 = 109 项）
- （2026-08 更新）**config/ 三文件已加入根 CMakeLists.txt** target_sources 与 include 路径；重新生成 CubeMX 后 cmake/stm32cubemx/ 不含业务代码属正常
- **串口配置模式接线点**：RTOS 版在 Core/Src/freertos.c MX_FREERTOS_Init 的 USER CODE Init 区（params_init 必须先于任务创建）；defaultTask 栈 128→512 字兼职 ParamCli_Poll()
