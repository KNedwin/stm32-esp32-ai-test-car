# 阅读指南

## 项目一句话
"stm32_rfid_tts_rtos"：STM32F103C8T6 RTOS 版，实现 U13T 读卡 + CN-TTS 语音播报 + 电机控制（多触发词停车/定时降速/参数化自动停车）+ LED + 数据输出口。（2026-08 更新：新增参数化底座——Flash 末页存储 + Setter 注入，及 USART3 串口配置模式（CLI 行协议 + PC 上位机），全部时序参数免编译可调。）

1. 新人: 01 → 09 → 03
2. 调参: 06 → 01（2026-08 起：改参数不必重编译，用 USART3 命令行或 tools/stm32_host 上位机，见 05_通信协议 §4）

4. 开发: 04 → 10

## 代码导航速查
- 参数默认值: config.h；运行时参数总表: config/nvs_params.h（g_params）
- 参数存储/注入: config/nvs_params.c（Flash 末页 0x0800FC00）
- 串口命令行: config/param_cli.c（USART3 行协议）；软跳烧录: config/isp_jump.c
- 触发词行为: Task/rfid_logic.c
- 电机时序: Task/motor_logic.c
- 读卡状态机: Task/rfid_task.c
- 协议解析: hardware/rfid_card/Card.c
- 构建: 见 01_项目介绍 §构建
