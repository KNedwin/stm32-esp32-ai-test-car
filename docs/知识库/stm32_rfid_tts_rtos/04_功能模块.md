# 功能模块

## 1. 读卡协议驱动（hardware/rfid_card/Card.c|h）
- **职责**: U13T 模块命令组帧/发送、响应帧逐字节解析、波特率切换、接收中断回调
- **对外 API**: SetBound115200()、ReadCard()、ReadBlock(block)、UartReceiveCommand(data)、HAL_UART_RxCpltCallback、HAL_UART_ErrorCallback
- **关键逻辑**:
  - 帧解析状态机：0x7F 帧头 → 长度(≤31 防护) → 命令码/参数 → 仅 0x91（读块）产生事件、0x90 分"读到卡号/无卡"、0xAC 忽略
  - 回调：temp_res==2 在 LEDLIGHT 态刷新 rfid_last_card_tick（LED 常亮依据）；temp_res==3 不再主动熄灯
  - ErrorCallback：ORE 溢出自愈（清标志 + 重装接收中断）

## 2. 触发/去重逻辑层（Task/rfid_logic.c|h，四版共享）
- **职责**: 触发词匹配（子串搜索）、一次性/计数型计数（首次数放行 + 10s 间隔）、去重判断、事件输出
- **对外 API**: RfidLogic_Init/Process/TriggerMatch/IsDup/UpdateSpeak/RuleCount/SetConfig
- **事件**: RFID_EV_NONE/SPEAK/SPEAK_FORCED/TRIGGER_STOP（位掩码）
- （2026-08 更新）新增 `RfidLogic_SetConfig(rfid_rule_rt_t[], count, dedup_ms, interval_ms)`：运行时注入规则表与去重/计数窗口；不调用则回落 TRIGGER_RULES 编译期默认。params_apply() 上电与 CLI 改参数后调用

## 3. 电机状态机逻辑层（Task/motor_logic.c|h，四版共享）
- **职责**: 绝对计时状态机（IDLE/RAMPUP/RUN/SLOW/STOPPING/WAIT/STOP）、多段降速窗口遍历
- **对外 API**: MotorLogic_Init/Step/IsInStopSequence/CalcStopTime/StateName/SetTiming
- **pending_trigger**: IDLE/RAMPUP 期触发挂起，RUN/SLOW 消费
- （2026-08 更新）新增 `MotorLogic_SetTiming(motor_timing_t)`：运行时注入晚启动/缓启动/H/I/降速窗口表；不调用则默认宏值。CalcStopTime 公式保留但已无调用方

## 4. 读卡应用状态机（Task/rfid_task.c）
- **职责**: 五态流转（EXIST→WAIT→RESDATA→LEDLIGHT→NONE）、播报、LED 保持（tick 法）、触发标志置位
- 单块读取（块4→回退块1）；播报缓冲统一 chinese_data[16] 并强制 0 结尾
- （2026-08 更新）上电 TTS 设置 <S>3/<V>6/<I>7（提示音改 7 号，与 ESP32 对齐）；LED 熄灭延时改 g_params.led_on_ms、LEDLIGHT 轮询间隔改 g_params.rfid_poll_ms（默认 800ms）

## 5. 电机应用层（Task/motor_control_task.c）
- **职责**: （2026-08 更新）Motor_Init 先 Motor_SetDirection(g_params.motor_dir) 再 MotorLogic_Init(…, g_params.autostop_ms)；每拍喂 MotorLogic_Step → Motor_Control 输出；状态变化边沿调试输出。电位器 20 次采样已移除

## 6. TTS 发送（hardware/USART/BSP_USART.c|h）
- **职责**: printf 重定向（__io_putchar 强定义 → USART2）、Usartx_SendString
- 注意：printf 归 TTS（语音），调试输出请用 Dbg_Printf（USART3）

## 7. 电机驱动（hardware/pwm/PWM.c|h）
- **职责**: TIM2 双通道 PWM2 启动；Motor_Control(speed 0~999)；Motor_SetDirection(dir)
- 映射：speed=0 → 双路 CCR=999（同电位停）；dir=0 → CH1=0、CH2=speed（差分 = speed/999×3.3V，正转）
- （2026-08 新增）Motor_SetDirection：dir=1 时角色交换（CH1 脉宽 + CH2 低）实现反转；由 Motor_Init 按 g_params.motor_dir 调用

## 8. LED（hardware/LED/led.c|h）
- **职责**: 三引脚（PC13/PB12/PA8）低电平亮；边沿触发调试输出（防 10ms 轮询刷屏）

## 9. 电位器采样（hardware/ADC/BSP_ADC.c|h）
- **职责**: Get_ADC_Value() 单次转换；公式（含 clamp）在 motor 层
- （2026-08 更新）**已退役**：全库无调用方（adc.c/BSP_ADC.c 留编译不删），MX_ADC1_Init 初始化仍执行

## 10. 数据输出口（hardware/DEBUG/Debug.c|h）
- **职责**: Dbg_Init（[SYS] boot）、Dbg_Printf（vsnprintf → USART3）；局部缓冲可重入
- （2026-08 更新）USART3 现兼任参数配置 CLI 的收发口；Dbg_Printf 单条限 128 字节（HELP 命令据此拆两行）

## 11. 参数存储与注入（config/nvs_params.c|h）（2026-08 新增）
- **职责**: params_t 同构参数结构 g_params；params_init() 读 Flash 末页 0x0800FC00（magic 0xA55A + CRC16MODBUS 校验，失败回落 config.h 默认宏并 sanitize）；params_save() 擦页+按字编程；params_apply() 注入 MotorLogic_SetTiming/RfidLogic_SetConfig；params_sanitize() 全字段范围钳制+窗口排序去重叠+规则去重
- F1 HAL 擦除常量为 FLASH_TYPEERASE_PAGES

## 12. 串口配置命令行（config/param_cli.c|h）（2026-08 新增）
- **职责**: USART3 行协议解析（行缓冲 192 字节、\r\n 结尾、支持退格）：HELP / GET all|<key>|win|rule / SET <key> <val>（标量+win_add/win_del/rule_add/rule_del）/ SAVE / DUMP / ISP / REBOOT
- 每条修改命令成功后自动 params_apply() 即时生效无需重启；SAVE 写 Flash 断电保持
- 应答一律走 Dbg_Printf（printf 重定向在 TTS 语音口 huart2，绝不能用于 CLI 应答）
- 接收为任务轮询 RXNE（ParamCli_Init 与 Poll 内均置 CR1_RE，CubeMX 只配了发送）

## 13. ISP 软跳烧录（config/isp_jump.c|h）（2026-08 新增）
- **职责**: param_cli_do_isp/do_reboot 弱符号钩子的实现；ISP_Enter() 关中断→停 SysTick→HAL_RCC_DeInit→设 VTOR=0x1FFFF000→换 MSP→跳转出厂系统 Bootloader（免 ST-Link 免 BOOT0 串口烧录）
- ⚠️ 跳转前需拔 U13T 读卡模块（其 RX 占用 USART1 干扰 Bootloader 应答），烧完插回
