# RTOS 版 - 项目说明（ESP32-S3）

> 本工程是 `stm32/rfid_tts_rtos` 的 ESP32-S3 复刻。功能规格与 STM32 版**完全一致**（详见 `stm32/rfid_tts_rtos/docs/02-项目说明.md`），本文档只重述要点并聚焦 ESP32 移植差异。

---

## 1. 功能规格（与 STM32 版一致）

| # | 功能 | 规格 | config.h 参数 |
|---|---|---|---|
| 1 | 晚启动 | 通电延时 A=2s 后电机启动 | `MOTOR_START_LATE_TIME_MS` |
| 2 | 缓启动 | B=4s 线性加速至目标速度 999 | `MOTOR_START_SLOW_TIME_MS` / `MOTOR_TARGET_SPEED` |
| 3 | 实时读卡 + LED | 读到卡亮；卡在线圈上持续亮；脱离 C=3s 后熄灭 | `LED_ON_TIME_S` |
| 4 | TTS 播报去重 | 单块 16 字节 GBK 播报；D=10s 内同内容不重复 | `SPEAK_DEDUP_TIME_S` |
| 5 | 定时降速 | 第 E=42s 起降为 F=50%，G=5s 后恢复（绝对计时一次） | `MOTOR_TIME_START_S` / `MOTOR_SPEED_PERCENT` / `MOTOR_TIME_DURATION_S` |
| 6 | 触发停车 | 多触发词规则表；停车序列 = 减速 H=2s + 静止 I=10s + 重新缓启动 | `TRIGGER_RULES` / `TRIGGER_STOP_RAMP_TIME_S` / `TRIGGER_WAIT_TIME_S` |
| 7 | 电位器自动停止 | 10s~600s 线性，绝对计时 | `RES_MAX` / `STOP_TIME_MIN_MS` / `STOP_TIME_MAX_MS` |
| 8 | 数据输出口 | 调试输出 `[SYS]/[RFID]/[LED]/[MOTOR]` 格式（console） | `DBG_*` |

触发词行为矩阵（太阳 1 次触发 / 地球 2 次触发间隔≥10s / 触发后上电周期内不再触发 / 停车期间不计数 / 触发播报强制）与 STM32 版逐条相同，由 `rfid_logic.c` 保证实现一致。

## 2. 硬件映射（ESP32-S3）

| 功能 | 引脚 | 外设/配置 |
|---|---|---|
| 读卡 U13T | GPIO10(TX)/GPIO11(RX) | UART1，9600→初始化后 115200 |
| TTS 模块 | GPIO12(TX)/GPIO13(RX) | UART2，9600 8N1 |
| 调试输出 | 原生 USB 口 | **USB-Serial-JTAG** console（免转接） |
| 电机 PWM | GPIO4/GPIO5 | LEDC 双通道互补，20kHz，10-bit |
| 电位器 | GPIO1 | SARADC1_CH0，12-bit |
| LED×3 | GPIO2/GPIO8/GPIO9 | 推挽，低电平亮，初始高 |

## 3. 架构

```
app_main()
 ├── 初始化：UART1(读卡,含波特率切换) / UART2(TTS) / LEDC(电机) / ADC / GPIO(LED) / Dbg
 ├── rfid_logic 状态清零；xTaskCreate 创建两个任务：
 │
 ├── RFID_Task（栈 4096B，优先级 5）          ── 读卡/播报/LED/触发（与 STM32 rfid_task 相同逻辑）
 │     EXIST→WAIT→RESDATA→LEDLIGHT→NONE 状态机
 │     UART1 轮询接收（Card_Uart_Poll 非阻塞，替代 STM32 中断回调）
 │     TTS 发送：uart_write_bytes(UART2, ...)（替代 printf→USART2）
 │
 └── Motor_Task（栈 2048B，优先级 1）         ── 绝对计时状态机（与 STM32 motor_control_task 相同）
       IDLE→RAMPUP→RUN/SLOW→STOPPING→WAIT→RAMPUP→STOP
       时间基准：esp_timer_get_time()/1000（毫秒，64 位无回绕）

UART1 接收（ESP-IDF driver/uart.h 轮询模式）
 ├── uart_driver_install 内部环形缓冲：应用层读取慢不丢字节，无 ORE 锁死问题
 ├── 任务/主循环每圈 Card_Uart_Poll()：uart_read_bytes 非阻塞取字节，
 │   逐字节喂帧解析状态机（与 STM32 UartReceiveCommand 相同，含长度防护）
 ├── 解析结果 → card_res_flag（与 STM32 版相同的五态标志）
 └── 溢出等错误由 ESP-IDF 驱动内部自愈（等效 STM32 版 ErrorCallback）
```

### 与 STM32 版的关键移植点

| 项 | STM32 版 | ESP32 版 |
|---|---|---|
| 时间基准 | `HAL_GetTick()`（32 位 ms） | `esp_timer_get_time()/1000`（64 位 us→ms，无 49.7 天回绕） |
| printf 角色 | printf→USART2（TTS） | **printf→console（调试）**；TTS 用 `uart_write_bytes` |
| UART 接收 | 中断 + `HAL_UART_RxCpltCallback` | 环形缓冲 + 轮询 `uart_read_bytes` 逐字节喂解析器 |
| 波特率切换 | `SetBound115200` + 重新 `HAL_UART_Init` | `uart_set_baudrate(UART1, 115200)`（先 9600 发命令） |
| PWM | TIM2 双通道 PWM2 模式 | LEDC 双通道（`ledc_channel_config`） |
| ADC | ADC1 轮询 | SARADC1 单次转换（`adc_oneshot` 新驱动） |
| 任务创建 | freertos.c USER CODE 区 | `xTaskCreate`（app_main 内） |
| 电机状态机 | motor_control_task.c 内嵌 | **motor_logic.c 纯逻辑层**（四版共享，主机可测） |
| TTS 默认设置 | 任务内直接 printf 指令 | **TTS_SetupDefaults()**（指令集下沉 tts.c） |
| 电机 1000s 上限 | `MOTOR_MAX_RUN_TIME_MS` | 同宏，时间基准换成 esp_timer |

### 数据输出协议（console，与 STM32 版格式一致）

```
[SYS] boot   LED=OFF MOTOR=STOP
[RFID] CC AB D1 F4
[LED] ON / [LED] OFF
[MOTOR] RAMPUP speed=345
```
电机状态枚举：`IDLE/RAMPUP/RUN/SLOW/STOPPING/WAIT/STOP`。

## 4. 文件清单

```
esp32/
├── components/common/        # ★ 共享业务组件（两版唯一维护点）
│   ├── config.h / pins.h     # 全部参数 + 引脚与外设实例映射
│   ├── rfid_logic.c|h        # 触发词/去重纯逻辑（与 STM32 版逐字相同）
│   ├── motor_logic.c|h       # 电机状态机纯逻辑（四版共享，主机可测）
│   ├── card_uart.c|h        # UART1 驱动 + U13T 命令组帧
│   ├── card_parse.c|h       # 帧解析纯逻辑
│   ├── tts.c|h              # TTS 发送 + TTS_SetupDefaults
│   ├── motor_drv.c|h        # LEDC 双通道互补驱动
│   └── led.c|h adc.c|h debug.c|h
└── esp32_tts_rtos/           # 本工程（仅应用层差异文件）
    ├── CMakeLists.txt        # EXTRA_COMPONENT_DIRS → ../components（必须在 project() 前）
    └── main/
        ├── CMakeLists.txt    # SRCS：app_main + rfid_task + motor_task，REQUIRES common
        ├── app_main.c        # 入口：外设初始化 + xTaskCreate 两任务
        ├── rfid_task.c|h     # 读卡任务（状态机；rfid_logic 决策）
        └── motor_task.c|h    # 电机任务（薄壳：喂 motor_logic）
```

## 5. 构建 / 烧录 / 调试

```bash
# 每次编译前激活环境
source <HOME>/.espressif/tools/activate_idf_v6.0.2.sh

cd esp32/esp32_tts_rtos
idf.py set-target esp32s3          # 首次（生成 sdkconfig）
idf.py build                       # 编译
idf.py -p /dev/ttyACM0 flash       # 烧录（USB-Serial-JTAG 口）
idf.py -p /dev/ttyACM0 monitor     # 监视（Ctrl+] 退出）
```

> ⚠️ **中文路径说明**：ESP-IDF 默认 picolibc 的 specs 机制不支持中文路径（本项目目录含中文），`sdkconfig.defaults` 已用 `CONFIG_LIBC_NEWLIB=y` 关闭 picolibc 绕开，**请勿删除该配置**。

编译前先跑主机测试（含共享组件漂移检查）：
```bash
cd esp32/tests && ./run_tests.sh   # rfid_logic + card_parse + motor_logic
```
