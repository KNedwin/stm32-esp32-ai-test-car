# 裸机版 - 项目说明（ESP32-S3）

> 本工程是 `stm32/rfid_tts_baremetal` 的 ESP32-S3 复刻。功能规格与 STM32 版**完全一致**，与同目录 RTOS 版 (`esp32_tts_rtos`) 也完全一致，**仅代码组织方式不同**：本版用**单任务超级循环**顺序执行两个状态机，不使用多任务。

---

## 1. 功能规格（与 STM32 版一致）

| # | 功能 | 规格 | config.h 参数 |
|---|---|---|---|
| 1 | 晚启动 | 通电延时 A=2s 后电机启动 | `MOTOR_START_LATE_TIME_MS` |
| 2 | 缓启动 | B=4s 线性加速至目标速度 999 | `MOTOR_START_SLOW_TIME_MS` / `MOTOR_TARGET_SPEED` |
| 3 | 实时读卡 + LED | 读到卡亮；卡在线圈上持续亮；脱离 C=3s 后熄灭 | `LED_ON_TIME_S` |
| 4 | TTS 播报去重 | 单块 16 字节 GBK 播报；D=10s 内同内容不重复 | `SPEAK_DEDUP_TIME_S` |
| 5 | 定时降速 | 第 E=42s 起降为 F=50%，G=5s 后恢复（绝对计时一次） | `MOTOR_TIME_START_S` / `MOTOR_SPEED_PERCENT` / `MOTOR_TIME_DURATION_S` |
| 6 | 触发停车 | 多触发词规则表；停车序列 = 减速 H=2s + 静止 I=10s + 重新缓启动 | `TRIGGER_RULES` / `TRIGGER_STOP_RAMP_TIME_S` / `TRIGGER_WAIT_TIME_S` |
| 7 | 电位器自动停止 | 10s~600s 线性，绝对计时 | `RES_MAX` / `STOP_TIME_MIN_MS` / `STOP_TIME_MAX_MS` |
| 8 | 数据输出口 | 调试输出 `[SYS]/[RFID]/[LED]/[MOTOR]` 格式（console） | `DBG_*` |

触发词行为矩阵与 STM32 版逐条相同（由 `rfid_logic.c` 保证实现一致）。

## 2. 硬件映射（ESP32-S3，与 RTOS 版完全相同）

| 功能 | 引脚 | 外设/配置 |
|---|---|---|
| 读卡 U13T | GPIO10(TX)/GPIO11(RX) | UART1，9600→初始化后 115200 |
| TTS 模块 | GPIO12(TX)/GPIO13(RX) | UART2，9600 8N1 |
| 调试输出 | 原生 USB 口 | **USB-Serial-JTAG** console（免转接） |
| 电机 PWM | GPIO4/GPIO5 | LEDC 双通道互补，20kHz，10-bit |
| 电位器 | GPIO1 | SARADC1_CH0，12-bit |
| LED×3 | GPIO2/GPIO8/GPIO9 | 推挽，低电平亮，初始高 |

## 3. 架构（单任务超级循环）

```
app_main()   ← ESP-IDF 默认任务（栈 4096B+）
 ├── 初始化（阻塞阶段）：
 │    UART1 波特率切换(9600→115200) → UART2(TTS) → LEDC → ADC → LED → Dbg
 │    TTS 设置指令 <S>3/<V>6/<I>0（阻塞延时）
 │    Motor_Init()：电位器采样 20 次 → stop_time；电机状态清零
 │    RfidLogic_Init()：触发/去重状态清零
 └── while(1) 超级循环（每次迭代让出 CPU：vTaskDelay(pdMS_TO_TICKS(1))）
      ├── RFID_Process()   ── 非阻塞读卡状态机（EXIST→WAIT→RESDATA→LEDLIGHT→NONE）
      │                        UART1 事件轮询（非阻塞方式：esp_timer 时间差驱动）
      │                        rfid_logic 决策 → 播报/触发标志
      └── Motor_Process()  ── 非阻塞电机状态机（绝对计时，esp_timer）
                               IDLE→RAMPUP→RUN/SLOW→STOPPING→WAIT→RAMPUP→STOP
```

### 关键设计

- **所有延时非阻塞**：用 `esp_timer_get_time()/1000` 时间差判断（与 STM32 裸机版 `HAL_GetTick` 差一致），主循环每圈两个状态机都推进
- **UART 接收**：UART1 事件队列 + 帧解析状态机。为保持超级循环结构，事件在 `RFID_Process()` 内轮询消费（`uart_get_event` 非阻塞）——与 STM32 裸机版"中断回调置标志、主循环消费"等价
- **TTS 发送阻塞**（9600，单块 16 字节 ≈17ms）：期间两个状态机停顿，缓启动按主循环圈更新，跳档毫秒级、功能不受影响（与 STM32 裸机版结论相同）
- **裸机版与 RTOS 版对比**：本版只有 app_main 一个任务，逻辑集中在两个 Process 函数；RTOS 版拆成两个任务可各自阻塞。功能、config.h、rfid_logic、硬件驱动完全相同，仅 main 层组织不同

### 与 STM32 裸机版的关键移植点

| 项 | STM32 裸机版 | ESP32 裸机版 |
|---|---|---|
| 主循环 | `while(1){ RFID_Process(); Motor_Process(); }` | 同（另加 `vTaskDelay(1)` 防看门狗） |
| 时间基准 | `HAL_GetTick()` | `esp_timer_get_time()/1000` |
| 初始化阻塞 | `RFID_Init()` 内 `HAL_Delay` | `vTaskDelay` 阻塞（初始化阶段） |
| printf 角色 | printf→USART2（TTS） | printf→console（调试）；TTS 用 `uart_write_bytes` |
| UART 接收 | 中断回调置位全局标志 | 事件队列 + Process 内轮询消费 |
| 电机驱动 | TIM2 PWM2 双通道 | LEDC 双通道互补 |

### 数据输出协议（console，与 STM32 版格式一致）

```
[SYS] boot   LED=OFF MOTOR=STOP
[RFID] CC AB D1 F4
[LED] ON / [LED] OFF
[MOTOR] RAMPUP speed=345
```
电机状态枚举：`IDLE/RAMPUP/RUN/SLOW/STOPPING/WAIT/STOP`。

## 4. 文件清单

```
esp32_tts_baremetal/
├── CMakeLists.txt            # 顶层
├── main/
│   ├── CMakeLists.txt        # idf_component_register(SRCS ... INCLUDE_DIRS ".")
│   ├── config.h              # 全部可调参数（与 RTOS 版/STM32 版一致）
│   ├── app_main.c            # 入口：阻塞初始化 + while(1) 超级循环
│   ├── rfid_process.c|h      # 非阻塞读卡状态机（RFID_Init/RFID_Process）
│   ├── motor_process.c|h     # 非阻塞电机状态机（Motor_Init/Motor_Process）
│   ├── rfid_logic.c|h        # 纯逻辑层（与 stm32 版逐字相同）
│   ├── card_uart.c|h         # U13T 协议 + UART1 事件处理
│   ├── tts.c|h               # TTS 发送（UART2）
│   ├── motor_drv.c|h         # LEDC 电机驱动：Motor_Control(speed 0~999)
│   ├── led.c|h               # LED_Sta
│   ├── adc.c|h               # Get_ADC_Value
│   └── debug.c|h             # Dbg_Printf → printf（console）
└── sdkconfig                 # idf.py set-target esp32s3 生成
```

## 5. 构建 / 烧录 / 调试

```bash
# 每次编译前激活环境
source <HOME>/.espressif/tools/activate_idf_v6.0.2.sh

cd esp32/esp32_tts_baremetal
idf.py set-target esp32s3          # 首次
idf.py build                       # 编译
idf.py -p /dev/ttyACM0 flash       # 烧录（USB-Serial-JTAG 口）
idf.py -p /dev/ttyACM0 monitor     # 监视
```

> ⚠️ **中文路径说明**：ESP-IDF 默认 picolibc 的 specs 机制不支持中文路径（本项目目录含中文），`sdkconfig.defaults` 已用 `CONFIG_LIBC_NEWLIB=y` 关闭 picolibc 绕开，**请勿删除该配置**。

编译前先跑主机测试：
```bash
cd esp32/tests && ./run_tests.sh
```

2. [ ] monitor 输出 `[SYS] boot   LED=OFF MOTOR=STOP`
3. [ ] 电机 A=2s 后缓启动，B=4s 平滑加速
4. [ ] 刷普通卡 → LED 亮 + TTS 播报；卡在持续亮；移开 C=3s 后灭
5. [ ] D=10s 内同卡不重复播报
6. [ ] E=42s 起降速 50%，G=5s 后恢复
7. [ ] "太阳"卡第 1 次 → 播报+停车（2s 减速 + 10s 静止后重启）；之后只播报
8. [ ] "地球"卡第 2 次（间隔≥10s）→ 播报+停车
9. [ ] 电位器旋转改变停车时间（10~600s）
10. [ ] 断电重启后触发词恢复可触发
11. [ ] TTS 发送期间（~17ms）电机缓启动无明显异常（轻微顿挫可接受）
